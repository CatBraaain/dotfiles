# chezmoi diff script spec

`scripts/chezmoi-diff.ts` は `chezmoi.yaml` の `diff.command` に指定されたカスタム diff コマンドであり、`just diff`(chezmoi diff)が各エントリを比較するときに呼ばれる。この spec はその入出力のふるまいを定める。

## 入力

- 引数に destination(展開先の実ファイル)と target(dist 配下の生成物)の2つのパスを受ける
- 2つのパスが揃わない場合はエラーで終了する

## 差分の無視

| 条件(両ファイルの内容) | diff 出力 | 終了コード |
| --- | --- | --- |
| 行末の違いのみが異なる | 出力しない | 0 |
| 両方が `.json` / `.jsonc` 拡張子で、閉じ括弧直前の空白・末尾カンマの有無と行末の違いのみが異なる | 出力しない | 0 |
| それ以外の内容差分がある | 出力する | diff の表示に従う |

- 行末の正規化: `\r\n` を除去し、末尾の `\n` を1個除去して比較する。これにより CRLF と LF、末尾改行の有無の差分は出ない
- 拡張子の判定: destination と target のパスがともに `.json` または `.jsonc` で終わるとき(大文字小文字を問わない)に末尾カンマの正規化を適用する。target が `/dev/null` や `NUL` の場合(削除エントリ)は適用しない

## JSON(C) の末尾カンマ正規化

- 比較の前に、閉じ括弧(`}` と `]`)の直前に連続する空白・カンマを取り除いたテキスト同士を比較する。`"a": 1,\n}` と `"a": 1}` は一致扱いになる
- 文字列リテラル(`"..."`)の中は変更しない。エスケープされた `\"` も文字列の一部として扱う
- JSONC コメントは解析せず、文字列外のテキストとして扱う。カンマと閉じ括弧の間にコメントが挟まるケースは吸収せず diff に出る。コメント内の閉じ括弧直前の空白・カンマも取り除かれるため、コメント内容の差分が diff に現れることがある
- 閉じ括弧直前以外の場所(開き括弧の直後、値の間など)の空白・カンマは正規化しない。要素間カンマや整形の空白差分は diff に出る
- JSON として不正なテキストでも、この変換は閉じ括弧直前の空白・カンマの除去のみを行い、他の文字は変更しない

## diff の表示

| 条件 | 表示方法 |
| --- | --- |
| `difft` が PATH にあり、両入力がファイル | `difft --color=always --display=inline --skip-unchanged --strip-cr=on --syntax-highlight=on` |
| `difft` がない | `git diff --no-index --ignore-cr-at-eol --color=always` |

- 入力のどちらかがディレクトリ、または `/dev/null` と `NUL`(削除エントリ)のとき、その側を一時的な空ディレクトリに置き換えて diff ツールへ渡す。difftastic はディレクトリ比較に対応しないためである
- git diff の出力から `\ No newline at end of file` の行は取り除いて表示する
- difftastic は構文木ベースで差分を取るため、JSON・JSONC の空白・コメント・カンマの差分は difftastic 使用時には表示されない

## 終了コード

- 差分なしで抜けたときは 0 で終了する
- difftastic 使用時は diff ツールの終了コードをそのまま伝播する
- git diff 使用時は差分ありを表す 1 を正常として扱い、2 以上のときだけ伝播する
