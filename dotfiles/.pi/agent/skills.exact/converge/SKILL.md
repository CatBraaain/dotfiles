# Converge

対象・目的・制約を `review` で評価し、収束条件を満たすまで修正・検証・再評価を反復する。

## 前提と知識

- **収束条件**は、ユーザーが明示した観測可能な終了条件である。明示がない場合は、最終の `review` における高重要度指摘が 0 件であること。
- `review` は、入力から対象、目的、契約、原則、根拠を抽出して評価項目を出力する正本である。

## 原則

- 評価項目と重要度は `review` の出力に従う。
- 収束条件を満たさない原因だけを、依頼された対象と目的の範囲内で最小に修正する。

## 契約

### 実行手順

1. `review` を、対象・目的・制約を特定できる入力へ適用する。この段階では対象を編集しない。
2. 収束条件の判定に必要な検証を実行し、`review` の結果と検証結果から収束条件を判定する。満たせば、収束したと報告して停止する。
3. 収束条件を満たさない原因となる評価項目または検証失敗を、依頼された対象と目的の範囲内で最小に修正する。
4. `review` を再適用し、手順2から繰り返す。

### 停止と編集境界

- 対象、目的、制約、またはユーザーが明示した収束条件を一意に特定できない場合は、必要な情報を質問して停止する。
- `review` が必要情報を質問して停止した場合は、その質問を解決するまで修正も収束判定も行わない。
- `review` と再評価では対象を編集しない。
- 依頼された対象と目的の範囲外の修正、または安全に実行できない変更が必要な場合は、必要な情報または許可を質問して停止する。
- オーナーが停止を指示した場合は、現在の評価結果と未解決項目を報告して停止する。
- 完了報告には、収束条件、最終の `review` 結果、実行した検証、収束条件を満たす根拠を含める。
