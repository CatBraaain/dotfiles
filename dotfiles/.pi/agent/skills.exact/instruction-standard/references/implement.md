# 指示テキスト作成手続き（any-implement 用）

any-implement が instruction-standard と組み合わせるときに適用する、指示テキストを書くための固有手続き。規則セットの組み立て、入力と完了範囲の確定、Verify による自己検証の骨格は any-implement が所有し、ここでは繰り返さない。

## 指示の構造

instruction-standard の記法選択規則に従い、目的に合う構造を1つ選ぶ。

## 執筆

選んだ構造で、対象の指示テキストを作成する。骨格は「目的 → 適用する場合と適用しない場合 → 手続き（選んだ記法） → 完了条件と出力形式」の順を基本とする。対象がファイルの場合は、ファイル種別に応じた配置規範を適用する。

## 依頼種別ごとの停止点

| 依頼 | 実行する範囲 | 停止条件 |
| --- | --- | --- |
| 指示テキストを書いて | 入力確定 → 構造選択 → 執筆 → Verify | Verify の適用項目がすべて通る |
| 指示テキストを整理して | 対象の構造確認 → 必要な再構成 → Verify | 整理前後で目的・入力・適用範囲の一致を対比して報告し、Verify が通る |
| 指示テキストを直して | 問題箇所の読解 → 当該箇所の修正 → Verify | 指摘ごとに解消後の該当箇所を対比して報告し、Verify が通る |
| 指示テキストをレビューして | any-review によるレビューへ切り替える | 指摘リストを出力した時点（対象テキストは編集しない） |
| 指示テキストの規範を変更して | instruction-standard の変更案を作る | 変更案を出力して承認待ちで停止する（承認前に対象テキストを直さない） |
