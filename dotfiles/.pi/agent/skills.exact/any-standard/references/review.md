# 規則スキル構成レビュー手続き（any-review 用）

any-review が any-standard と組み合わせるときの、汎用デフォルトへの差分。照合軸・重要度・指摘形式・skip・サマリの骨格は any-review が所有する。

- レビューへの入力は、対象スキルのファイル群に加えて汎用3スキルと既存 standard の一覧を含める（ドメイン重複・正本所在・汎用混入の検出に必要）。
- 出力の見出しは Structure / Purpose を使う（oracle 適合 / 目的適合に対応）。
- Structure 軸の種別は出典とし、any-standard のセクション・規則名を置く。主な種別:
  - **命名違反** — `xxx-standard` 命名・既存規則スキルの改名強制（§命名と種別）
  - **種別違反** — 単発スキルの standard スキル化、standard の単発スキル化（§命名と種別）
  - **構成違反** — 汎用デフォルトで足りる `references/` の配置（§構成契約）
  - **正本所在違反** — 規則・軸の汎用スキルへのコピー（§役割分担と正本所在）
  - **汎用混入** — ドメイン固有でない指示の SKILL.md 規則本体への記述。汎用3スキルとの重複、複数 standard で使える汎用指示（§構成契約）
  - **汎用スキル違反** — 汎用3スキルのドメイン規則所有、4つ目の汎用スキルの作成（§規則スキル構成、§役割分担と正本所在）
  - **ドメイン重複** — 複数 standard への規則重複所有（§役割分担と正本所在）
