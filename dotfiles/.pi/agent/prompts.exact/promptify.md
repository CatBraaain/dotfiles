# 次セッション用プロンプトの作成

次のセッションにそのまま貼り付けて使える、自己完結したプロンプトを作成してください。
依頼内容から、次のどちらのモードかを判断してください。追加指示でモードが明示されている場合は、それを優先します。
- **引き継ぎモード**: 現在のセッションの作業を続ける場合。現在の依頼、完了した作業、確認済みの事実、変更したファイル、未解決の問題、次に行うべき作業を整理する。
- **独立モード**: 現在のセッションとは無関係なプロンプトを作る場合。現在の会話内容や作業状況を前提にせず、追加指示に書かれた目的・条件だけからプロンプトを作る。
モードが曖昧で、追加指示もない場合は引き継ぎモードにする。どちらのモードでも、次のセッションのエージェントが現在の会話履歴を読めなくても実行できる自己完結した内容にする。

## 手順

1. 選択したモードに必要な情報を整理する。引き継ぎモードでは現在のセッションから、独立モードでは追加指示から情報を抽出する。
2. 必要なら、次のセッションで最初に読むべきファイルと確認すべきコマンドを具体的に含める。
3. 以下の追加指示がある場合は、選択したモードに従ってプロンプトの内容に反映する。

```text
/next-session $@
```

4. 作成したプロンプト本文だけを、`bash` ツールでクリップボードへコピーする。説明文、Markdown のコードフェンス、コピー用のコマンド自体はクリップボードに含めない。
5. クリップボードへのコピーには、環境で利用できるコマンドを次の順で使用する。
   - `wl-copy`
   - `xclip -selection clipboard`
   - `xsel --clipboard --input`
   - `pbcopy`
   - Windows の `clip`
6. 複数行の内容は、クォート付きヒアドキュメントなどを使い、特殊文字や改行を変えずにコピーする。コピーに失敗した場合は成功したと報告せず、原因と手動で取得するためのプロンプトを示す。
7. `/new-session` は実行しない。次のセッションへの切り替えはユーザーが行う。

コピーが完了したら、クリップボードへコピーしたことと、次にユーザーが `/new` を実行して貼り付ければよいことだけを簡潔に報告する。
