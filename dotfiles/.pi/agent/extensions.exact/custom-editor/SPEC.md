# custom-editor拡張Spec

この拡張は、pi の入力欄エディタを `CustomEditor` を継承した独自実装へ差し替える。キー割り当てで変えられないエディタの組み込み挙動を上書きするカスタマイズの受け皿であり、個々のカスタマイズはエディタ実装として `core.ts` に置く。対象読者は、pi標準エディタの組み込み挙動を部分的に変えたいユーザーである。

`index.ts` は tuiモードの `session_start` で、`core.ts` のエディタ実装を `setEditorComponent` に登録する。

この拡張が提供するエディタ実装は次のとおりである。

## NoPromptHistoryEditor

pi の入力欄で up / downキーによって送信済みプロンプトが読み込まれる挙動（エディタ内の履歴ブラウズ）を無効化する。エディタ内の上下移動に up / down を使うためのエディタである。

仕組み: pi本体はエディタの up / downカーソルハンドラ内に履歴ブラウズを埋め込んでおり、キー割り当てだけでは無効化できない。そこでこのエディタは送信済みプロンプトの蓄積（`addToHistory`）を抑止する。履歴が空であるため、up / down は通常のカーソル移動として振る舞う。

### 振る舞い

| 開始時の状態 | 操作 | 結果 |
| --- | --- | --- |
| 送信済みプロンプトが存在する | 入力欄の行頭で up を押す | 前回のプロンプトは読み込まれない。テキスト・カーソル位置とも変化しない |
| 送信済みプロンプトが存在する | 入力欄の末尾で down を押す | 履歴への復帰は発生せず、テキストは変化しない |
| 複数行入力中でカーソルが 2行目以降にある | up / down を押す | 通常の上下カーソル移動が行われる |
| 1行入力の途中でカーソルが 1行目にある | up を押す | カーソルが行頭へ移動する（pi標準の挙動を維持） |

### 適用範囲

- 無効化するのは入力欄（エディタ）内の up / down履歴ブラウズのみである。
- submit、autocomplete、undo、kill-ring など pi標準のエディタ機能は変更しない。
- keybindings の既定割り当ては変更しない。履歴ブラウズを別キーで使いたい場合は `tui.editor.historyPrevious` / `tui.editor.historyNext` に割り当てる（本エディタの対象外）。
