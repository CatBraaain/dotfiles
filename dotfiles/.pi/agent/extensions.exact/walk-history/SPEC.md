# walk-history拡張Spec

この拡張は、セッション木の現在位置を user発言単位で前後させる `/back`・`/forward` コマンドと、同じ処理を実行する `ctrl+up`・`ctrl+down` ショートカットを提供する。`/undo`・`/redo` はそれぞれ `/back`・`/forward` のエイリアスである。対象読者は、エージェントのツール利用を 1つずつ巻き戻すことなく自分の発言単位でやり直したいユーザーである。

## /back の振る舞い

| 開始時の状態 | 操作 | 結果 |
| --- | --- | --- |
| アクティブブランチに user発言が 1件以上ある | `/back` を実行する | エージェントが処理中ならその turn を中断した後、ブランチの末尾から見て最後の user発言と、その発言より後ろの entryすべてが会話から除かれ、その発言の直前の状態へ移動する。要約を生成せず、確認ダイアログを表示せず、即座に移動する。除かれた位置は forward の復帰対象になる |
| 直前の `/back` と同じ | `/back` をもう1回実行する | その時点の末尾から見て最後の user発言に対して同じ規則が適用され、実行するたびに user発言1つ分遡る |
| アクティブブランチの user発言が会話の最初の 1件のみ | `/back` を実行する | 会話が空になり、その発言のテキストがエディタに入る |
| アクティブブランチに user発言がない | `/back` を実行する | 会話を変えず、通知を表示せずに終了する |
| `/tree` や `/fork` で移動した後 | `/back` を実行する | 移動後のアクティブブランチ上で上記の規則と同じように動く |

## /forward の振る舞い

| 開始時の状態 | 操作 | 結果 |
| --- | --- | --- |
| 直前に `/back` を実行した | `/forward` を実行する | その `/back` で除く前に居た位置へ会話を移動する。エージェントが処理中ならその turn を中断した後、即座に移動する。エディタの内容は変化しない |
| `/forward` を連続実行する | `/forward` をもう1回実行する | 未復帰の `/back` がある限り、後から実行した `/back` から順に1つずつ戻る |
| 戻る対象の entry がセッションから消滅している(compaction 等) | `/forward` を実行する | 消滅した対象を飛ばし、残っている対象があればそこへ戻る |
| 有効な復帰対象がない | `/forward` を実行する | 会話を変えず、通知を表示せずに終了する |
| `/tree` で別の位置へ移動した後 | `/forward` を実行する | 未復帰の `/back` が残っていれば、移動先に関係なくその復帰対象へ戻る |
| 戻る先の entry が user発言だった(送信前の位置へ戻る形) | `/forward` を実行する | 会話上の位置は組み込みの `/tree` でその user発言を選んだ場合と同じになるが、エディタの内容は変化しない |
| `/forward` のナビゲーションが他の拡張によってキャンセルされた | `/forward` をもう1回実行する | 同じ対象への復帰を再試行できる |

## ctrl+up / ctrl+down ショートカット

| 開始時の状態 | 操作 | 結果 |
| --- | --- | --- |
| 入力エディタが入力を受け付ける状態 | `ctrl+up` を押す | `/back` を実行した場合と同じ結果になる。連打すると 1押下 = 1発言ずつ順に遡る |
| 同上 | `ctrl+down` を押す | `/forward` を実行した場合と同じ結果になる |
| fullscreen の transcript 表示 | `ctrl+up` / `ctrl+down` を押す | 本拡張は動かない。transcript 側にこのキーの割り当てはないため、表示は変化しない |
| fullscreen の transcript 表示 | `alt+up` / `alt+down` を押す | 組み込みの発言ジャンプ(`tui.altScreen.previousPrompt` / `tui.altScreen.nextPrompt`)が動く。本拡張のショートカットではない |

## エディタの復元

| 開始時の状態 | 操作 | 結果 |
| --- | --- | --- |
| `/back` で user発言を取り消した直後 | エディタを確認する | 取り消された発言のテキスト（組み込みの `/tree` がエディタへ復元するテキストと同一）でエディタの内容が置き換わっている。組み込みの `/tree` でその userメッセージを選んだ場合と同じ状態になる |
| 取り消された発言のテキストがエディタに入った状態 | そのまま送信する | 送信内容は新しい分岐として記録され、取り消される前のブランチは残る |
| `/back` のナビゲーションが他の拡張によってキャンセルされた | エディタを確認する | エディタの内容は変化しない |

## 復帰対象の寿命

- 復帰対象の記憶は pi のプロセス内のみ。pi の再起動、`/new`、`/fork`、セッション切替、`/reload` で消える。セッションをまたいだ `/forward` は提供しない。
- セッション木に残る過去の分岐そのものは本拡張が変更せず、`/tree` で参照できる状態を保つ。

## 適用範囲

- 本拡張が巻き戻すのは会話のみで、ファイルや git の状態は変更しない。
- 組み込みの `/tree`、`/fork`、`/new` の挙動は変更しない。
