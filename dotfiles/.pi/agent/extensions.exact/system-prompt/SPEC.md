# system-prompt 拡張 spec

pi がモデルへ送る system prompt の標準部分を、この拡張が保持する文面と組み立てから生成し、送信時に置き換える拡張の観測可能な振る舞いを定める。読者はこの spec だけを読んで内容を go/no-go するユーザーと、実装・検証の担当者。

- 用語: run は 1 回のユーザー入力から応答完了までの処理単位。force run は、いずれかの拡張が run 開始時に system prompt 全文を指定した run。それ以外を通常 run と呼ぶ。標準部分は pi 本体が生成する system prompt 本文（固定文と tools・rules・docs・AGENTS・skills・cwd 等のセクション）。標準部分の後ろに他拡張が付けた文は追記と呼ぶ。
- 基準版: 現在インストールされている pi 本体の標準生成。初期状態のこの拡張は基準版と同一の文字列を生成する。

## 振る舞い

| 条件・状態・入力 | 操作 | 結果 |
| --- | --- | --- |
| 通常 run / モデルリクエストの送信直前 | 先頭 system message を拡張の組み立てへ置き換える | 送られる system prompt の標準部分が拡張の文面・組み立てから生成される。文面を編集していなければ基準版と同一になる |
| 通常 run / run 中に有効ツールが増減 | 増減後の状態を次のリクエストへ反映する | tools・rules が増減後の内容になり、run 開始時の状態に凍結されない |
| 通常 run / AGENTS・skills・cwd・他拡張のセクション | run 開始時点の内容を反映する | 各セクションが pi 本体と同じ位置・形式で本文に載る |
| 通常 run / 拡張が所有しないセクション（他拡張の追記セクション等） | pi が描画した内容をそのまま採用する | 他拡張の追記が失われない |
| force run / 全文が拡張の標準描画と前方一致 | 標準部分だけを拡張描画へ置換する | 追記部分はそのまま保持される |
| force run / 全文が拡張の標準描画と前方一致しない | 何もしない | 送信内容は拡張がない場合と同一になる |
| 常時 | ツール定義を扱わない | ツール宣言（名前・説明・引数）は拡張がない場合と同一になる |
| 常時 | セッション履歴を書き換えない | transcript の記録は pi 標準どおり。拡張による置換は送信時にのみ現れる |
| TUIモードでセッション開始（新規起動・復元） | 折りたたみインジケータ（実効 system prompt の総文字数・行数の要約1行）をエディタ上端の widget に表示する | 全文は自動表示されない。表示は閲覧のみ |
| TUIモード / インジケータ表示中 | ctrl+shift+p、`/system-prompt` コマンド、またはインジケータのクリックで展開する | 展開時点の実効 system prompt 全文（ctx.getSystemPrompt()）をスクロール可能なオーバーレイで開く。esc・q・Enter で閉じられ、閉じてもセッション継続に影響しない |
| UIなしモード（RPC・JSON・print）でセッション開始 | 何もしない | インジケータも全文表示も発生しない |
| 閲覧表示中・インジケータ表示中 | prompt・tools・transcript を変更しない | 表示は読み取りのみ。閲覧の開閉によって送信内容や履歴は変わらない |
| 拡張の文面・組み立て定義を編集 | 以降のリクエストへ反映する | 編集後の文面で生成される。pi 本体の更新では拡張の文面は変わらない |

run 開始後に skills の読み出しツールが read から bash へ切り替わる場合のみ、skills セクションの案内文が run 開始時の文言になる。

インジケータの要約はセッション開始時のプロンプトから作る。全文閲覧のオーバーレイは展開の時点で実効プロンプトを読み直し、それ以降の変更は次の展開まで反映されない。クリックによる展開はマウスイベントを配信する fullscreen モードでのみ機能し、通常モードでは ctrl+shift+p と `/system-prompt` コマンドが常に利用できる。これらの表示は上記の送信時置換の経路と独立して動く。
