# Tool Path Formatting Spec

## 対象

この仕様書は、main agent と subagent のコール行に表示するパスを確認するオーナーを読者とする。対象は `read`、`write`、`edit` であり、作業ディレクトリはそのツールを実行するセッションの cwd である。

## 表示

パスを表示するコール行では、入力パスを cwd から解決して次の形式で表示する。

| 解決先 | 表示 |
| --- | --- |
| cwd 自体 | `.` |
| cwd の配下 | cwd からの相対パス（`./` から始める。例: `./childfolder`） |
| cwd の親またはそれ以外 | 絶対パス |

`read` がスキル名を表示する既存の形式では、パスを表示しない。
