# cd セッション移行拡張 Spec

## 対象

pi のセッションを会話・コンテキストごと指定ディレクトリへ移す拡張。エージェント用に `cd` ツールを提供する。配置先は `dotfiles/.pi/agent/extensions.exact/cd/`。

## 入口

正規入口はツールのみ。人間がコマンドを直接使う運用はしない。

| ツール | 役割                                               |
| ------ | -------------------------------------------------- |
| `cd`   | セッションの作業ディレクトリを指定パスへ切り替える |

セッション切替が必要なため、内部コマンド `/cd <path>` をフォローアップのユーザーメッセージとして発火して実行する（pi のツール実行コンテキストからはセッション切替を呼べないため）。内部コマンドはコマンドパレットに表示されるが、正規入口ではない。

## cd ツール

| 入力                   | 結果                                                                                                              |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------- |
| path（必須）           | `/cd <path>` をフォローアップのユーザーメッセージとして発火する。ツールの戻り値は「発火をキューした」旨のテキスト |
| 発火したコマンドの成否 | コマンド側の通知・セッション切り替えに現れる                                                                      |

発火に成功した `/cd` が移動に成功した場合、切替完了後に新セッションで再開メッセージ（ユーザーメッセージ `Continue the task in the new working directory.`）を送信し、エージェントのループを継続する。

## /cd の振る舞い

path は先頭の `~` をホームディレクトリに展開し、相対パスは現在の cwd 基準で解決する。

| 状態                                  | 操作         | 結果                                                                                                            |
| ------------------------------------- | ------------ | --------------------------------------------------------------------------------------------------------------- |
| 存在するディレクトリのパス            | `/cd <path>` | 移動手順の全ステップが成功し、解決済みパスを cwd とするセッションへ切り替わる。移動通知に移動先のパスを表示する |
| path 未指定                           | `/cd`        | エラー通知のみ。状態は変わらない                                                                                |
| パスが存在しない / ディレクトリでない | `/cd <path>` | エラー通知のみ。状態は変わらない                                                                                |
| セッションが未保存（ファイル無し）    | `/cd <path>` | エラー通知のみ。状態は変わらない                                                                                |

### 移動手順（上から順に、失敗したら以降を中止してエラー通知）

1. 現セッションを fork した新規セッションファイルを作成（会話履歴は全てコピー、header の `cwd` を移動先パスに書き換え、`parentSession` に元セッションのパスを記録）
2. `ctx.switchSession` で新セッションへ切り替え。AGENTS.md・`.pi/`・skills・extensions は移動先の内容で再読込される

本拡張は git コマンドを実行しない。worktree や git の状態は一切変更しない。

## システムプロンプトへの露出

| 項目               | 内容                                                                                                                                                                                                                                                             |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `promptSnippet`    | セッションの作業ディレクトリを切り替える旨の1行                                                                                                                                                                                                                  |
| `promptGuidelines` | bash の `cd` はシェルごとに閉じるためセッションの cwd は変わらない。セッションごと別ディレクトリ（git worktree・別リポジトリ等）へ移すときに `cd` ツールを使う。編集を伴う作業の着手前は、git worktree 運用 rule（rules/git-worktree-strategy.md）に従って worktree を作成して `cd` で移動する |

`path` パラメータの説明文には、絶対パス（`~` 展開可）であることを含める。
