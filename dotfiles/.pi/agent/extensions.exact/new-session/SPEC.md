# new-session 拡張機能 Spec

オーナーが手動で新セッションへ切り替えるための prompt command を2つ登録する。正式コマンドは `/new-session`、短縮コマンドは `/ns` とする。Pi 組み込みの `/new` は登録・変更せず、その動作を保持する。

## コマンド一覧

| コマンド | 引数 | 結果 |
| -------- | ---- | ---- |
| `/new-session` | 任意の文字列 | 完全にクリーンな新セッションへ切り替える |
| `/ns` | 任意の文字列 | `/new-session` と同じ処理で完全にクリーンな新セッションへ切り替える |

両コマンドとも、コマンド一覧（`/help` など）に説明文 "Start a clean new session. An optional argument is placed in the new session's editor as a draft." を表示する。

エージェント向けツール、エージェント起点の処理、確認ダイアログは提供しない。

## 引数とドラフト

コマンド引数は、新セッションの入力欄に未送信のドラフトとして設定する。

| 入力 | 新セッションの入力欄 |
| ---- | -------------------- |
| `/new-session hi` | `hi` |
| `/ns hi` | `hi` |
| `/new-session   ` | 空 |
| `/ns   ` | 空 |
| `/new-session` または `/ns` | 空 |

引数の前後にある空白は除去する。空白だけの引数は空のセッションとして開く。

## 新セッションのクリーン性

`/new-session` と `/ns` は `parentSession` と `setup` を渡さずに新セッションを開始する。前セッションの会話、要約、ファイルパスなどは一切引き継がれない。引数がある場合、その文字列だけが未送信ドラフトとして入力欄に設定される。

## 組み込みコマンド `/new`

この拡張は `/new` を登録せず、フックも追加しない。Pi 組み込みの `/new` の動作を変更しない。
