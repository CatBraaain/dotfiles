# skill-shortcut拡張機能Spec

skillコマンドを `/skill:foo` ではなく `/foo` で呼べるようにする。補完（`/` 入力時の候補）にも `/foo` で表示する。

## 補完の表示

`/` で始まる入力時、各skill は `/skill:` 付きではなく `/` 付きで候補に出る。

| ユーザー入力 | 候補に表示されるもの |
| --- | --- |
| `/` | 全skill が `/foo` `/bar` … と表示される |
| `/fo` | `/foo`（`fo` の文字が順番どおり現れるskill） |
| `/sht` | `/skill-shortcut`（`s` → `h` → `t` の順に現れるskill） |
| `/sk` | `s` → `k` の順に現れる候補 |

非skill のコマンド（ビルトイン・拡張コマンド・promptテンプレート）は `/` 付きでそのまま候補に出る。`skill:` の剥離は skill にのみ適用され、非skill は書き換えない。

### 書き換えの要否と補完表示

`/` 入力時の候補の書き換え結果は次のとおり。

| カーソルより前の入力 | 補完表示 |
| --- | --- |
| `/` で始まり空白を含まない | 一致する候補を裸名（`skill:` 剥離済み）で表示する |
| `/` で始まるが、書き換え後に一致候補が 0件 | 補完ポップアップを表示しない |
| `/` で始まらない、または空白を含む | 候補を書き換えない |

候補を確定したときの入力欄への挿入は pi既定の動作に従う（この拡張は確定時の挿入テキストを変更しない）。`@` 等によるファイル補完の要否判定も pi既定の動作に従い、pi側に判定が用意されていない場合はファイル補完を行う。

## コマンドの実行

送信した `/...` をどう処理するか。

| 入力 | 名前の状態 | 結果 |
| --- | --- | --- |
| `/foo` | skill に存在する | その skill を実行 |
| `/foo <args>` | skill に存在する | その skill を実行し、`<args>` を渡す |
| `/foo` | skill に存在しない（promptテンプレート・他コマンド・未定義） | 変換せず、通常通り処理 |
| `/skill:foo` | （直接入力） | そのままskill を実行 |
| （拡張が内部的に送信した入力） | — | 変換せず、通常通り処理 |

## 名前の衝突

`/foo` が複数の種類で同名の場合の優先順位。

| `/foo` と同名のもの | 実行されるもの |
| --- | --- |
| 拡張コマンド + skill | 拡張コマンド |
| promptテンプレート + skill | promptテンプレート |
| skill のみ | skill |

## 起動直後の補完

pi起動直後（最初のプロンプト送信前）から `/foo` が補完に出る。
