# replace-context拡張機能Spec

この拡張は、同一セッション内で作業phaseのコンテキストを切り替える `replace_context` ツールを提供する。対象読者は、次のphaseを始めるユーザーとmain agentである。切替前の会話はセッションのraw履歴に残る。

## 入力

| 入力 | 条件 | 意味 |
| --- | --- | --- |
| `reason` | 前後の空白を除いて空でない文字列 | コンテキストを切り替える理由 |
| `handoff` | 前後の空白を除いて空でない文字列 | 次のphaseへの自然言語プロンプト |
| `class` | 省略可。前後の空白を除いて空でない文字列 | 次のphaseの実効クラス |

`handoff` は続行目的、承認済みspecとworkファイルのパス、決定事項、作業・検証状態、未決事項、完了条件を含められる。次のagentは指定されたファイルを読んで続行する。

## 利用条件

`replace_context` はmain agentだけが使う。コンテキストをリセットして長い次の作業phaseへ移る場合に限り、収束ループ開始前、またはseniorによるレビュー・実装の完了後に次の長いphaseがある場合に呼び出す。レビュー・実装の完了だけでは呼び出さない。

`finish wt`・`discard` の承認待ち、user の判断待ち、単なる作業完了報告では呼び出さず、main agent は `Ready` または `Waiting` として通常の質問で終了する。切替後のmain agentは次のphaseを別のseniorへ委譲する。

収束条件を満たしたmain agentは、`replace_context` を呼び出さずユーザーへ結果を報告する。

## クラス指定

`class` を指定したときは、切替後の実効クラスをその名前に変更することを求める。省略したときは現在のクラスを維持する。切替条件と必要な承認を確認した後、agents拡張の汎用 `agents:class-change` イベントへ要求し、その適用処理の完了を待ってから圧縮境界を返す。切替条件を満たさないときは要求しない。クラスの候補評価・モデル切替処理は持たず、agents拡張に委ねる。

要求には `preserveManualSelection: true`・`requiredAgent: "main"`・`source: "agent"` を指定する。適用された場合のクラス表示は `(agent)` となる。手動モデル選択中はクラス変更を無視し、コンテキスト切替だけを行う。agents拡張がない場合も待ち続けず、コンテキスト切替だけを行う。適用処理が例外で失敗した場合はエラー通知して圧縮境界を返さない。適用待ちの後も中断・セッション変更を確認する。クラス変更そのものの条件と結果はagents拡張のSpec「クラス変更イベント」が定める。

## コンテキスト切替

有効な入力による呼出しを含むturnのツール結果が保存された時点で切り替える。同一セッションファイルへ圧縮境界を追加し、境界前の会話・要約・ツール結果を以後のモデル入力から外す。raw履歴とセッションIDは維持する。

`handoff` を前後の空白除去以外は変更せず圧縮要約として保存する。要約を生成するLLM呼出しは行わない。モデルには既存のsystem prompt・tool定義、pi標準の要約ラッパーに入った `handoff`、境界以後のメッセージを渡し、その文脈で自動続行する。待機キューのユーザー入力も保持する。

## 承認と回数

回数は現在のbranch上で成功した自動切替の回数である。通常のユーザー入力または承認以降、次の周期を繰り返す。

| 回数 | 次の切替 | 成功後の回数 |
| --- | --- | --- |
| 0 | 自動 | 1 |
| 1 | 自動 | 2 |
| 2 | 理由と `handoff` を表示して承認を求める | 承認時は0 |

通常入力は対話画面またはRPCからのユーザー入力を指し、回数を0へ戻す。拡張が送る合成入力では戻さない。再開・reloadだけでは回数を戻さない。tree移動では移動先branchの回数を使う。保存された回数が不正なら承認を求める。

承認UIは選択式の `Yes, replace context` と `No, stay (reason next)` を使う。選択式UIがなければ確認ダイアログを使う。拒否・選択キャンセル時は任意の理由を入力し、`no(<理由>)` を現在のagentへfollowUp送信する。理由が空または入力キャンセルなら `no()` を送る。拒否では切替も回数加算も行わない。

## 切り替えない条件

| 条件 | 結果 |
| --- | --- |
| 入力が欠落・文字列以外・空白のみ | ツールエラーを返す |
| 対話UIがない | エラーを通知する。自動切替にも同じ条件を適用する |
| 同じturnに複数のhandoff呼出しがある | 現在の文脈と回数を維持する |
| turnまたは同じturnのツールがエラー・中断で終了する。入れ子のツール記録が不完全、失敗、未完了である | 現在の文脈と回数を維持する |
| 承認UIが失敗する | エラーを通知し、現在の文脈と回数を維持する |
| 選択・確認・拒否理由の入力待ちの間にセッションやbranch末尾が変わる | 警告を通知し、切替と拒否通知を止める。現在の文脈と受信した入力を維持する |

## 既存の新セッション操作

`/new-session`、`/ns`、pi組み込みの `/new` は、ユーザーが空の新セッションを開始する操作として維持する。
