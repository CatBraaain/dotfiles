# Footer

## 目的

Pi の TUIフッターで、標準フッター相当の情報に加えて、現在のセッションIDと担当情報を確認できるようにする。

## 表示

プロバイダーごとの使用量が表示される場合、フッターはその下に置く。フッター内は、セッション情報、キャッシュ統計とモデル、拡張ステータスの順に表示する。

### セッション情報

1. 作業ディレクトリ。ホームディレクトリ配下は `~` から始める。Gitリポジトリ内では ` (ブランチ名)` を続ける。
2. worktree。ディレクトリの末尾名を取得順に `, ` で区切り、`worktree: ` を前置する。
3. ticket。`ticket: project/id` の形式で表示する。
4. セッション名。
5. セッションID。`session: セッションID` の形式で行の右端に表示する。

値のない worktree、ticket、セッション名は省く。worktree と ticket 内の制御文字、双方向テキストの制御文字、行・段落区切り文字は `\uXXXX` 表記にする。

要素間を半角スペースで2列以上空け、入るだけ同じ行に並べる。現在の行の残り幅に収まらない要素から、次の行に表示する。要素が単体でも端末幅に収まらない場合は、要素の末尾を切り詰める。

### キャッシュ統計とモデル

左側に、セッション全体の累積値を空白区切りで表示する。値が0の項目も0として表示する。

- 入力トークン: `↑値`
- 出力トークン: `↓値`
- キャッシュ読み取りトークン: `R値`
- キャッシュ書き込みトークン: `W値`
- キャッシュ読み取りまたは書き込みがある場合の直近キャッシュヒット率: `CH値%`（キャッシュ利用がない場合は `CH0.0%` と表示する）
- 累積コスト: `$金額`

左側の末尾に現在のコンテキスト使用率とコンテキストウィンドウを `使用率%/上限` の形式で表示する。使用率が不明な場合は `?/上限` と表示する。

右側にモデルIDを表示する。利用可能なモデルプロバイダーが複数あり、表示幅に収まる場合は `(プロバイダー名) ` を前置する。推論対応モデルでは、続けて ` • thinking level` を表示する。thinking level が `off` の場合は ` • thinking off` を表示する。

トークン値は、1000未満を整数、1000以上10000未満を小数1桁の `k`、10000以上1000000未満を整数の `k`、1000000以上10000000未満を小数1桁の `M`、それ以上を整数の `M` で表す。

### 拡張ステータス

`setStatus()` で登録された拡張ステータスをキーのアルファベット順で表示する。

## 色

すべての行を dim（グレー）で表示する。

## 更新

| 状態 | 表示される結果 |
| --- | --- |
| Pi が起動する | 現在のセッション情報を表示する |
| 新規セッション、セッション再開、セッションのフォークが完了する | 新しいセッションの情報へ切り替える |
| Gitブランチが変わる | 作業ディレクトリ行のブランチ名を更新する |
| セッションの usage、モデル、thinking level、コンテキスト使用量が変わる | 次回の描画で最新値を表示する |

保存対象のセッションでは、起動・切り替え時と以後5秒ごとに、[`pi-mux metadata <session-id>`](../../../../.local/cli.exact/pi-mux/SPEC.md#metadata) の `worktrees` と `ticket` を取得する。取得中に次の周期が来ても、取得を重ねない。セッション切り替え時は前の担当表示を消す。取得に失敗した場合は通知せず、現在のセッションの直近の表示を保つ。

## 表示幅

各行は端末幅を超えない。キャッシュ統計とモデルの行で幅が不足する場合は、右側の情報から切り詰める。拡張ステータスも端末幅に合わせて切り詰める。

## 表示例

```text
~/projects/example (main)             session: 12345678-1234-1234-1234-abcdefabcdef
↑57k ↓1.8k R94k W0 CH88.7% $0.015 20.6%/272k    (openai-codex) gpt-5.6-luna • high
```

セッション開始直後（usage がすべて0）の下段:

```text
↑0 ↓0 R0 W0 CH0.0% $0.000 3.2%/1.0M    (openai-codex) gpt-5.6-luna • high
```
