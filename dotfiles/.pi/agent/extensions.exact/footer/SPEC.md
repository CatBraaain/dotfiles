# Footer

## 目的

Pi の標準フッター相当の情報を2行で表示し、上段右端に現在のセッションIDを追加する。対象は Pi の TUI フッターである。

## 表示

フッターは次の順序で表示する。

1. 上段左側に作業ディレクトリを表示する。ホームディレクトリ配下は `~` から始める。Git リポジトリ内では、続けて ` (ブランチ名)` を表示する。セッション名がある場合は、さらに ` • セッション名` を表示する。
2. 上段右側に `session: セッションID` を表示する。セッションIDは省略せず全文字を表示する。
3. 下段左側に、セッション全体の累積値を空白区切りで表示する。値が0の項目も0として表示する。
   - 入力トークン: `↑値`
   - 出力トークン: `↓値`
   - キャッシュ読み取りトークン: `R値`
   - キャッシュ書き込みトークン: `W値`
   - キャッシュ読み取りまたは書き込みがある場合の直近キャッシュヒット率: `CH値%`（キャッシュ利用がない場合は `CH0.0%` と表示する）
   - 累積コスト: `$金額`
4. 下段左側の末尾に現在のコンテキスト使用率とコンテキストウィンドウを `使用率%/上限` の形式で表示する。使用率が不明な場合は `?/上限` と表示する。
5. 下段右側にモデルIDを表示する。利用可能なモデルプロバイダーが複数あり、表示幅に収まる場合は `(プロバイダー名) ` を前置する。推論対応モデルでは、続けて ` • thinking level` を表示する。thinking level が `off` の場合は ` • thinking off` を表示する。
6. `setStatus()` で登録された拡張ステータスを3行目以降にキーのアルファベット順で表示する。

トークン値は、1000未満を整数、1000以上10000未満を小数1桁の `k`、10000以上1000000未満を整数の `k`、1000000以上10000000未満を小数1桁の `M`、それ以上を整数の `M` で表す。

## 色

すべての行を dim（グレー）で表示する。

## 更新

| 状態 | 表示される結果 |
|---|---|
| Pi が起動する | 現在のセッション情報を表示する |
| 新規セッション、セッション再開、セッションのフォークが完了する | 新しいセッションの情報へ切り替える |
| Git ブランチが変わる | 作業ディレクトリ行のブランチ名を更新する |
| セッションの usage、モデル、thinking level、コンテキスト使用量が変わる | 次回の描画で最新値を表示する |

## 表示幅

各行は端末幅を超えない。表示幅が不足する場合は、各行の右側情報を切り詰めて表示する。

## 表示例

```text
~/projects/example (main)             session: 12345678-1234-1234-1234-abcdefabcdef
↑57k ↓1.8k R94k W0 CH88.7% $0.015 20.6%/272k    (openai-codex) gpt-5.6-luna • high
```

セッション開始直後（usage がすべて0）の下段:

```text
↑0 ↓0 R0 W0 CH0.0% $0.000 3.2%/1.0M    (openai-codex) gpt-5.6-luna • high
```
