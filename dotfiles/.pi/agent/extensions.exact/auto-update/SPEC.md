# auto-update 拡張機能 Spec

pi 起動時に、拡張機能（パッケージ）の更新をバックグラウンドで1回だけ実行する。ユーザーの操作を待たず、更新結果も表示しない。

## 実行条件

`session_start` イベントの `reason` によって、更新を実行するかどうかが決まる。

| `session_start.reason` | 更新を実行するか |
| ---------------------- | ---------------- |
| `startup`              | する             |
| `reload`               | しない           |
| `new`                  | しない           |
| `resume`               | しない           |
| `fork`                 | しない           |

更新を実行するのは、上表の `reason` に加えて、セッションが TUI モード（`ctx.mode` が `"tui"`）で起動しているときだけである。rpc・json・print モード（パイプ入力 `-p` を含む）では、`reason` が `startup` でも更新しない。

## 頻度制限（throttle）

最後に `pi update` の spawn に成功してから 12 時間が経過していないときは、更新を実行しない。

## 更新の実行

実行は `pi update --extensions` を子プロセスとして起動する。起動後は親プロセスに待たせず、切り離して（detach）実行する。

| 項目 | 内容 |
| --- | --- |
| 実行コマンド | `pi update --extensions` |
| 起動方法 | detach（親から切り離し）、`stdio` 無視、シェル経由 |
| 待機 | しない（`unref` して即座に返る） |
| 結果・エラーの表示 | しない |

## スコープ外（やらないこと）

- 更新結果の通知・ログ表示はしない。
- 起動（`startup`）以外のセッション開始では更新しない。
