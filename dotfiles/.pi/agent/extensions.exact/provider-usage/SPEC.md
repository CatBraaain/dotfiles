# Provider usage の表示

この文書は、pi の provider-usage拡張を利用・保守する人に向けた、残り時間・列配置・セッション終了時の更新の正本である。利用制限枠の残量率を示す `short`・`long` の各表示に適用する。

## 残り時間

リセット日時から表示時点の現在日時を引き、正の残り時間は分単位で切り上げる。切り上げた値を1日24時間・1時間60分として分解する。単位は `d` が日、`h` が時間、`m` が分を表す。

有効な日時から求めた残り時間は、必ず分まで表示する。最上位の単位の数値はゼロ埋めせず、表示する下位の時間・分は2桁にする。下位の値が0でも、その単位を表示する。

| 条件 | 表示形式 | 例 |
| --- | --- | --- |
| 切り上げ後が1分以上60分未満 | 分 | `1m`、`54m` |
| 切り上げ後が60分以上1日未満 | 時間・2桁の分 | `1h05m`、`2h00m` |
| 切り上げ後が1日以上 | 日・2桁の時間・2桁の分 | `5d14h10m`、`5d00h00m` |
| リセット日時が現在以前 | 0分 | `0m` |
| リセット日時の文字列を日時として解釈できない | 不明 | `?` |

例えば、残り23時間59分30秒は `1d00h00m` と表示する。

## 列配置

取得したプロバイダーを入力順に1行ずつ表示し、プロバイダー名・`short`枠・`long`枠を `|` で区切る。既知のプロバイダー名は `openai-codex` を `codex`、`command-code` を `command`、`zai` を `zai` と表示し、それ以外は元の名前を使う。

| 列 | 配置と幅 |
| --- | --- |
| プロバイダー名 | 左寄せ。表示中の名前の最大端末表示幅にそろえる |
| 残量率 | `%` を含めて4文字幅で右寄せ。残量率がない枠は `—` を同じ幅で右寄せする |
| 残り時間 | 右寄せ。`short`・`long` ごとに、表示中の残り時間の最大幅にそろえる |

残量率と残り時間の間に `↻` を置き、その後ろに右寄せ用の半角スペースを加える。残量率またはリセット日時がない枠は残り時間と `↻` を空白にし、後続の列の位置を保つ。その枠の残り時間が全行にないときは、残り時間と `↻` 用の幅を確保しない。行末の空白は省く。

```text
codex   | short    —            | long  76% ↻  5d19h00m
command | short 100% ↻ 5d20h00m | long 100% ↻ 28d13h00m
zai     | short   0% ↻       4m | long  64% ↻  5d14h00m
```

## セッション終了時の更新

起動時と拡張の再読み込み時に使用量を取得し、その後は5分間隔で更新する。新規セッション・再開・fork の開始時は、使用量の取得と定期更新を開始しない。

| 状態・入力 | 操作 | 結果 |
| --- | --- | --- |
| 定期更新が動作中 | 終了・再読み込み・新規セッションへの切替・再開・fork に伴うセッション終了 | 定期更新を停止し、以後の旧セッション向け取得とUI操作を行わない |
| セッション終了後に取得が完了 | 成功・空結果・失敗のいずれかを受け取る | 旧セッションの結果を破棄し、UI操作や未捕捉例外を発生させない |
| 終了処理が完了済み | 終了通知を再度受け取る | 停止状態を保ち、例外を発生させない |
| 新しい拡張が表示中 | 古い拡張の取得が完了 | 新しい表示を維持する |
