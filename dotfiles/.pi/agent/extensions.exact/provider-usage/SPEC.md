# Provider usage の残り時間表示

この文書は、pi の provider-usage拡張を利用・保守する人に向けた、リセットまでの残り時間の振る舞い正本である。利用制限枠の残量率を示す `short`・`long` の各表示に適用する。

## 残り時間

リセット日時から表示時点の現在日時を引き、正の残り時間は分単位で切り上げる。切り上げた値を1日24時間・1時間60分として分解する。単位は `d` が日、`h` が時間、`m` が分を表す。

有効な日時から求めた残り時間は、必ず分まで表示する。最上位の単位の数値はゼロ埋めせず、表示する下位の時間・分は2桁にする。下位の値が0でも、その単位を表示する。

| 条件 | 表示形式 | 例 |
| --- | --- | --- |
| 切り上げ後が1分以上60分未満 | 分 | `1m`、`54m` |
| 切り上げ後が60分以上1日未満 | 時間・2桁の分 | `1h05m`、`2h00m` |
| 切り上げ後が1日以上 | 日・2桁の時間・2桁の分 | `5d14h10m`、`5d00h00m` |
| リセット日時が現在以前 | 0分 | `0m` |
| リセット日時の文字列を日時として解釈できない | 不明 | `?` |

例えば、残り23時間59分30秒は `1d00h00m` と表示する。

## 記号と空白

残量率と残り時間の間に `↻` を置く。`↻` の前後には、それぞれ半角スペース1個を置く。

```text
zai short 8% ↻ 54m · long 66% ↻ 5d14h10m
zai short 8% ↻ 2h00m · long 66% ↻ 5d00h00m
```
