# undo 拡張機能 Spec

この拡張は、直前のユーザーの発言以降を 1 コマンドで取り消す `/undo` コマンドを提供する。対象読者は、エージェントのツール利用を 1 つずつ巻き戻すことなく自分の発言単位でやり直したいユーザーである。

redo は提供しない。巻き戻した分岐はセッション木に残るため、復元が必要な場合は `/tree` を使う。

## /undo の振る舞い

| 開始時の状態 | 操作 | 結果 |
| --- | --- | --- |
| アクティブブランチに user 発言が 1 件以上ある | `/undo` を実行する | エージェントが処理中ならその turn を中断した後、ブランチの末尾から見て最後の user 発言と、その発言より後ろの entry すべてが会話から除かれ、その発言の直前の状態へ移動する。要約を生成せず、確認ダイアログを表示せず、即座に移動する |
| 直前の `/undo` と同じ | `/undo` をもう 1 回実行する | その時点の末尾から見て最後の user 発言に対して同じ規則が適用され、押すたびに user 発言 1 つ分遡る |
| アクティブブランチの user 発言が会話の最初の 1 件のみ | `/undo` を実行する | 会話が空になり、その発言のテキストがエディタに入る |
| アクティブブランチに user 発言がない(空の会話) | `/undo` を実行する | 会話は変化せず、戻せる発言がないことを通知する |
| `/tree` や `/fork` で移動した後 | `/undo` を実行する | 移動後のアクティブブランチ上で上記の規則と同じように動く |

## エディタの復元

| 開始時の状態 | 操作 | 結果 |
| --- | --- | --- |
| `/undo` で user 発言を取り消した直後 | エディタを確認する | 取り消された発言のテキスト（組み込みの `/tree` がエディタへ復元するテキストと同一）でエディタの内容が置き換わっている。組み込みの `/tree` でその user メッセージを選んだ場合と同じ状態になる |
| 取り消された発言のテキストがエディタに入った状態 | そのまま送信する | 送信内容は新しい分岐として記録され、取り消される前のブランチは残る |
| `/undo` のナビゲーションが他の拡張によってキャンセルされた | エディタを確認する | エディタの内容は変化しない |

## 適用範囲

- 本拡張が巻き戻すのは会話のみで、ファイルや git の状態は変更しない。
- 組み込みの `/tree`、`/fork`、`/new` の挙動は変更しない。
