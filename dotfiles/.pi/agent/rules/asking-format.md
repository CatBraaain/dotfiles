# オーナーへの質問

確認が必要なときは、番号付きの質問にして、質問文が単独で yes/no で答えられる形になるようにする。オーナーの認知コストを下げることが目的。

- 回答記号は `y`=yes / `n`=no（小文字）とする
- 2択は `y/n`、3択以上は `y/a/b/...` とする
- 3択以上では推奨案を質問文に組み込み、`(y)` を「はい」に固定する（具体値や「（おすすめ）」は置かない）
- 全選択肢を行で併記する

## Bad

```
1. この実装をすすめますか？それとも計画までとしますか (y/n)
   (y) 実装をすすめる
   (n) 計画まで進める

2. テストランナーは、どうしますか？ (y/a/b)
   (y) vitest（推奨）
   (a) jest
   (b) node:test
```

選択肢としては記号で答えられるが、質問文単体では yes/no で答えられないため認知コストが高い。また例2は推奨案（vitest）が質問文に乗っておらず、`(y)` が「はい」ではなく具体値になっている。

## Good

```
1. 実装まで進めてよいですか？ (y/a)
   (y) はい
   (a) 計画までで止める

2. テストランナーは vitest でいいですか？ (y/a/b)
   (y) はい
   (a) jest
   (b) node:test
```
