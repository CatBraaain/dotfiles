# coding-standard 出典対応表

SKILL.md の50項目と `sources.md` の助言の対応。この表は SKILL.md から出典を削除した分の情報を開発用に保持する。

判定の種類:

| 判定 | 意味 |
| --- | --- |
| 採用 | SKILL.md の項目として収録（対応項目ID） |
| 採用（背景） | 項目ではないが、節イントロやカタログ全体の前提に反映 |
| 包含 | 特定項目の適用例の一部として暗黙に含まれる |
| 非採用 | 収録していない（理由を記載） |
