# skills 同期フック spec

`dotfiles/.agents/skills.exact/.pre-chezmoi.ts` の観測可能な振る舞いの仕様。対象は、Bun ランタイムでこのファイルを実行したときの、入力（`.pre-chezmoi.skills.yaml` と `~/mirrors/github.com/` 以下のミラーと環境変数）から出力（カレントディレクトリの skill ツリー、標準出力・標準エラー出力、終了コード）への変換。読者は、この spec だけを読んで要件を承認するオーナーと、実装・テストの担当者。

- このフックは pre-chezmoi.spec.md §2 のローカルフックとして、`dotfiles/.agents/skills.exact` に対応する `dist/` フォルダをカレントディレクトリにして起動される。単独で実行したときも、カレントディレクトリを出力先として同じ振る舞いをする。
- 経路表記: `~` はホームディレクトリ。hook 相対のパスはこのフックを置くディレクトリからの相対。
- 用語: ミラーは `~/mirrors/github.com/<owner>/<repo>` にある Git リポジトリの作業コピー。

## 1. 入力

| 入力 | 値 |
| --- | --- |
| config | hook 相対の `.pre-chezmoi.skills.yaml` |
| ミラーの配置先 | `~/mirrors/github.com/<owner>/<repo>` |
| 出力先 | カレントディレクトリ |
| 環境変数 `PRE_CHEZMOI_FORCE_PULL` | `1` のとき pull を強制（§3） |

## 2. config

config は `externalSkills` マッピングを 1 つ持つ。キーは `<owner>/<repo>`、値は skill パスの配列で、配列の順序は保持する。

| 値の要素 | 解釈 |
| --- | --- |
| 文字列 | `{ path: その文字列 }` と同じ |
| `{ path, appendSkillMd }` | `path` はミラー内の glob（§4）。`appendSkillMd` は SKILL.md へ追記するテキスト（§6） |

config がこの形を満たさないときは §8 の文言で異常終了する。

## 3. ミラー同期

config の各リポジトリを独立に処理する。リポジトリ間の順序は不定で、あるリポジトリの pull の失敗が他のリポジトリのログやコピーに影響しない。致命的なエラー（異常終了）のときの他リポジトリの動作は§8のとおり。同じリポジトリの複数エントリは、1 回の同期のあと配列順に処理する。

| ミラーの状態 | 前回 pull の記録（§3.1） | 操作 | 出力 |
| --- | --- | --- | --- |
| なし | — | `git clone --depth 1 --quiet https://github.com/<owner>/<repo>.git` を実行してミラーを作る | 成功: stdout へ `mirror: cloned <owner>/<repo>`、pull 時刻を記録。失敗: §8 |
| あり | なし、または 6 時間以上前 | ミラー内で `git pull --ff-only --quiet` | 成功: stdout へ `mirror: pulled <owner>/<repo>`、pull 時刻を記録。失敗: stderr へ `warning: git pull failed for <owner>/<repo>: <gitのstderr>`、処理は続行 |
| あり | 6 時間以内 | なし | stdout へ `mirror: fresh <owner>/<repo>` |

- `PRE_CHEZMOI_FORCE_PULL=1` のときは記録に関係なく pull する行を取る。
- 6 時間の境界: 前回 pull からちょうど 6 時間が経過した時点で、pull する行に変わる。
- pull が失敗したときは pull 時刻を記録しない。次回実行で再試行する。

### 3.1 前回 pull の記録

前回 pull の記録は、ミラーの `.git/pre-chezmoi-pull-time` に記録時刻の UNIX 時間（ミリ秒）として書く。clone 成功時と pull 成功時に記録する。ファイルがない、内容が数値でないときは、記録なしとして扱う。

## 4. skill の解決

エントリの `path` を、ミラー相対の glob として解釈し、ミラー内のディレクトリへ一致させる。

| 条件 | 結果 |
| --- | --- |
| ディレクトリ 1 件に一致 | そのディレクトリをコピー元にする |
| 0 件（ファイルにのみ一致する場合を含む） | §8 で異常終了: `skill path matched nothing in mirror: <path>` |
| 2 件以上 | §8 で異常終了: `skill path matched multiple directories in mirror: <path>` |

## 5. skill のコピー

コピー元ディレクトリを、出力先 `<path の最終パス要素>` へコピーする。

| 項目 | 振る舞い |
| --- | --- |
| 再帰 | サブディレクトリを含めてコピーする |
| `.git` | 名前が `.git` のエントリは、どの深さでもコピーしない |
| 既存ファイル | 残す。ミラー側の内容で上書きしない（ローカル修正を優先する） |
| 既存ディレクトリ | その中へマージする |
| chezmoi 属性 prefix | `after_` `before_` `create_` `dot_` `empty_` `encrypted_` `exact_` `executable_` `external_` `literal_` `modify_` `once_` `onchange_` `private_` `readonly_` `remove_` `run_` `symlink_` のいずれかで始まる名前は `literal_<名前>` に変えてコピーする |

コピー元に存在しないファイルを出力先から削除しない。

## 6. appendSkillMd

エントリに `appendSkillMd` がないときは何もしない。あるときは、コピー先の `SKILL.md` に対して:

| SKILL.md の状態 | 結果 |
| --- | --- |
| なし（空のファイルを含む） | `appendSkillMd` のテキストで作成する |
| あり・末尾が改行 | そのまま末尾へ `appendSkillMd` を追記する |
| あり・末尾が改行でない | 改行 1 つを挟んでから `appendSkillMd` を追記する |

## 7. ログ

| 出力（stdout） | 时机 |
| --- | --- |
| `mirror: cloned <owner>/<repo>` | clone 成功の直後（§3） |
| `mirror: pulled <owner>/<repo>` | pull 成功の直後（§3） |
| `mirror: fresh <owner>/<repo>` | pull をスキップしたとき（§3） |
| `skill: <path の最終パス要素> (<owner>/<repo>)` | その skill のコピーと appendSkillMd が完了したとき（§5・§6） |

git コマンド自身の進行出力は抑制されるため、stdout には上表の行だけが現れる。リポジトリ間の順序は不定のため、これらの行の現れ順は実行ごとに異なり得る。§3 の警告（stderr）も同様に、他の行と混ざり得る。

## 8. 成功と失敗

すべてのエントリのコピーが完了したとき、終了コード `0` で終了する。

次のいずれかが起きたとき、終了コード `0` 以外で終了する。stderr へ、先頭に `dotfiles/.agents/skills.exact/.pre-chezmoi.ts: ` を付けたエラーメッセージを 1 行出力する。

| 条件 | エラーメッセージ（先頭を除く） |
| --- | --- |
| config に `externalSkills` マッピングがない | `.pre-chezmoi.skills.yaml must have an externalSkills mapping: <configのパス>` |
| リポジトリの値が配列でない | `externalSkills.<owner>/<repo> must be an array` |
| 配列の要素が文字列でも `{ path, appendSkillMd }` でもない | `externalSkills.<owner>/<repo>[<index>] must be a path string or { path, appendSkillMd }` |
| `appendSkillMd` が文字列でない | `externalSkills.<owner>/<repo>[<index>].appendSkillMd must be a string` |
| clone が失敗した | `git clone failed for https://github.com/<owner>/<repo>.git: <gitのstderr>` |
| skill の解決が §4 の不一致・複数一致 | §4 の文言 |
| config が YAML としてパースできない | YAML パーサーのエラーメッセージ |

エラー発生後も他のリポジトリのコピーが続行するかどうかは保証しない。出力先の rollback も行わないため、出力先は処理途中の状態になり得る。
