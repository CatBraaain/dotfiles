# Coding

ソースコード・テスト・ビルド/検証コード・CSS・設定ファイル（YAML・TOML・JSON 等）の編集前に、対応する技法カタログを read して適用する。差分レビューでコード品質を評価するときも同じカタログを使う。自然言語のテキストファイルは writing skill の対象。

`/tmp` 等の使い捨て検証スクリプトと、コードを変更・評価しない調査には使わない。

## 手順

1. `references/readable-coding.md` と `references/maintainable-coding.md` を read する
2. カタログ本文の指示に従い、全項目と照合して適用する
