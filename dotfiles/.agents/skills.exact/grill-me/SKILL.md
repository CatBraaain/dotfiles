# Grill Me

1. 結論を左右する前提と、どの判断がほかの判断に依存するかを整理する。自分で確認できる事実は調べ、ユーザーには選択が必要なことを尋ねる。
2. 独立した質問と、先に見通せる依存質問を同じ回に出す。判断に必要な前提、推奨とその理由、代替案を示す。表示条件を含む質問の書式は `AGENTS.md` の「Asking Format」に従う。
3. 回答後は、条件が成立し、回答が得られた質問だけを確定する。条件が成立しない質問は、その配下と回答も採用しない。条件が未確定の質問は保留し、新たに必要になった質問と未回答の質問を次の回で扱う。
4. 未決の質問がなくなったら合意を要約する。合意の確認と、合意した内容を実行する承認は分ける。
