# ANSI Chat

## チャット本文への出力

pi-tui では、assistant の本文に含めた ANSI装飾が表示される環境がある。Markdown しか表示できないと決めつけず、依頼された表示を本文へ直接出す。

- 出力先は assistant の本文とする。Bashツールの標準出力や、実行用コードの提示で代用しない。
- ANSIシーケンスの先頭には実際の ESC文字（U+001B）を使う。`\x1b`・`\u001b`・`ESC` という文字列のまま出すと装飾にならない。
- 表示例はコードフェンスやインラインコードで囲まず、独立した行として出す。
- 行末には実際の ESC文字に続く `[0m` を置き、後続の本文へ装飾を持ち越さない。

## UI の再現

1. 対象の描画処理と現在のテーマを読み、文字色・背景色・状態ごとの色を確認する。単純な色のデモなら、この調査は不要。
2. 背景色、余白、改行、行幅、時刻の位置を含めて再現する。背景部分は空白も着色し、文字数ではなく全角文字などを考慮した表示幅で揃える。
3. 固定幅で示す場合は幅を添える。取得できない色やサンプルの文言・時刻は、実際の設定や値と区別する。
4. 折りたたみ・展開などは状態ごとの静的な例として示す。チャット内で実際に操作できるとは説明しない。

## 出力例

次の例は文字色と背景色を直接表示する形式であり、各装飾の先頭には実際の ESC文字を含む。本文へ出すときは外側のコードフェンスを外す。配色はデモ用であり、UI再現では確認したテーマ色に置き換える。

```text
[31mRed[0m / [32mGreen[0m
[48;2;37;65;49m[38;2;222;224;225m Done.              [0m
```

表示できないと伝えられた場合は、実際の ESC文字を含むか、本文へ直接出したかを先に確認する。別の端末やクライアントでも同じ表示になるとは保証しない。
