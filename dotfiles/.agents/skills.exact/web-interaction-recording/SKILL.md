# Web Interaction Recording

## 録画の境界

対象は、ユーザーが録画を求めた Playwright Test、または Vitest から Playwright ライブラリでブラウザーを操作する E2E テスト。動画でレビューする操作と画面上の結果を基に、録画専用の E2E シナリオを作る。関連する操作はレビュー時に流れを追える範囲で1本にまとめ、動画の本数を抑える。複数ページにまたがる場合は発生順にページ映像をつなぎ、各操作と結果が追える1本にする。つなげられない場合は動画と対象を分け、収まらない操作を明示する。各シナリオに結果を検証する自動アサーションを置く。通常の E2E には録画用の設定変更・実行・動画生成を適用しない。既存のランナーを録画のためだけに移行しない。

録画は操作と画面上の結果を人がレビューするためのもの。ランナーの自動テスト結果と、ユーザーが動画を見て行う go/no-go 判断を区別する。画面上の表示からアサーションの成否を推測せず、実際に実行したランナーの結果を自動テストの合否とする。テストデータの選定はテストケースを設計する側の責務であり、この skill は入力値の検査やマスクを追加しない。

## 録画を組み込む

対象プロジェクトのランナー、既存の E2E helper / fixture、reporter、動画の保存先、主要なウェブ使用フローを調べ、既存の構成に合わせて録画ケースだけに録画を組み込む。Playwright のページ動画を WebM で保存し、`ffmpeg` で無音の H.264 MP4 に変換する。ページ映像の最上部には describe 階層を含むテストタイトルのタイトル帯を置く。既存の装飾・変換処理が要件を満たすなら重複して追加しない。

失敗したテストでも動画の保存を試み、保存・変換の失敗はテスト結果を上書きせず別に報告する。録画 context を自分で管理する場合は、ページと context を閉じて録画を確定させてから WebM の保存・変換を待つ。並列実行や再試行では出力名の衝突を避け、各テストの最後の試行で対象操作と結果を収めた MP4 を1本確定する。最終試行を選別できない場合は、制約と残った動画を報告し、各テスト1本と主張しない。

録画を有効にした設定や helper が後続の通常実行でも録画する場合、依頼が一時的な録画なら組み込みの変更を残さない。報告する MP4 は実際に出力されたパスから確認し、変換エラーはテスト合否とは別に報告する。MP4 が欠けた場合は録画完了としない。

## 操作と変化を見せる

録画開始前に画面サイズを一定にし、必要なテストだけを実行する。録画ケースの各操作と、シナリオで確認する各画面変化について、操作の予告、操作する箇所、操作そのもの、変化した箇所を動画内で対応付ける。操作前に短い「操作 → 期待する画面変化」のステップラベルを表示し、結果が確認できるまで維持する。遷移・リロード・別タブでは新しい document やページにも装飾を設置し直し、ページ映像を切り替える区間でもステップラベルが途切れないようにする。結果が現れたら「時間の間隔」に従って確認対象を枠で囲み、複数箇所が変化するならシナリオで確認する順に、確認枠とその見出しを1箇所ずつ示す。同時に複数の確認枠・見出しを表示せず、各箇所の表示時間と切替間隔は「時間の間隔」に従う。ページ本来の更新は順次表示のために遅らせない。対象が消える場合は消える前の位置を示し、消えた後の結果や空になった領域も示す。遷移・リロードでは移動先の画面の確認箇所も示す。枠やラベルを UI、成功判定、実際の表示内容と誤認させず、変化を覆わない位置に置く。待機と操作の速度は「時間の間隔」の最低時間に従い、実際の操作順やアサーションの意味は変えない。

### ステップの対応と表示状態

録画専用シナリオでレビューする操作と結果を発生順にステップ `1` から `N` まで番号付けする。`N` は操作開始前に確定する。帯の `STEP <番号> / <総数>`、分割進行、全ステップ一覧、主注釈の番号は同じステップを指し、操作の予告から結果の確認まで番号を維持する。ページ・frame の切替でも番号をリセットしない。全ステップ一覧は常時表示し、全件の番号と短縮名を保つ。ステップラベルの操作・期待する画面変化と短縮名は、動詞で始まる操作と対象・現象で書く（例: `input postcode`、`press tab`、`click express button`）。空のシナリオを架空のステップで埋めず、録画対象がないことを報告する。

主注釈の番号は1か所に付ける。操作対象の枠があればその見出し、枠がなければ文字入力では入力帯、キー・スクロール操作ではキー表示、それらもなければステップラベルを主注釈とする。帯と全ステップ一覧は進行を示す別の表示であり、主注釈に数えない。結果の見出しには番号を重複させない。

| 場面 | 当該ステップの番号バッジ装飾 | 当該ステップの一覧・セグメント |
| --- | --- | --- |
| 操作の予告から操作開始まで（操作待ち） | 数字だけ | 現在 |
| 操作を行っている間（操作中） | 数字と小さなスピナー | 現在 |
| 操作終了から最初の確認枠を表示するまで（確認待ち） | 数字を囲む大きなリング | 現在 |
| 確認対象が画面に現れ、結果の確認枠を示している間（結果表示、箇所の切替間隔も含む） | 数字と緑のチェック | 完了 |
| 全確認箇所の表示時間を満たしてから次の操作を予告する | 前の番号はチェックを維持、次の番号は数字だけ | 前のステップは完了、次は現在 |

先のステップは未着手、過去のステップは完了とする。最後の結果表示でも帯は `STEP N / N` と最後の操作・期待結果を維持し、全件を完了表示にする。操作待ち・確認待ち・操作中・結果表示・未着手・現在・完了は文書内の状態名とする。一覧のチェックと一覧・進行の緑の完了表示は、動画で確認する結果の強調を開始したことだけを示す。アサーションの合格を示さず、結果が現れて最初の確認枠を表示するまでは完了へ進めない。画面上の結果が現れた後でテストが失敗しても、テスト合否を注釈から推測しない。

### 注釈の見た目

録画処理が映像へ付加する表示（録画注釈）のデザイン正本はこの節である。共通注釈は、タイトル帯とステップ進行、ステップラベル、全ステップ一覧とその番号バッジ、対象・結果の枠と見出し、ステップ番号と単色 SVG アイコン、カーソルとその残像、波紋、入力帯、キー表示で構成する。録画注釈の全体は共通注釈と、ユーザーが承認したプロジェクト固有の表示で構成される。時計・章・時刻索引・追加の拡大像など、この節にない表示はユーザーの承認を得てプロジェクト固有の表示としてのみ加える。ページ本来の UI は録画対象であり、注釈の配色を適用しない。ページ・frame の識別バッジは共通注釈に含めない。

見た目は、sans-serif の本文と mono の進行数字・番号、余裕のある内側余白、薄い中立色の外周で階層を作る。面の不透明度は色トークンに従い、現在は塗りチップ、完了は緑の輪郭チップで区別する。操作種別による色分けはせず、緑は結果・完了だけに用いる。背景のぼかし、装飾グラデーション、文字の影、チップやパネルのグローは付けない。

#### 寸法・文字・共通面

`W`・`H` はタイトル帯を除くページ映像の幅・高さ、`s = max(1, W / 1280)` は寸法倍率。以下の px 値を `s` 倍し、最終映像上の寸法とする。1280px 未満でも文字・余白を縮めない。比率値は `W`・`H` に直接適用する。映像・ページ領域の寸法は録画全期間で固定し、注釈を収めるためにサイトを縮小・リサイズ・切り抜きしない。タイトル帯の領域はページ映像と重ならないよう確保する。

幅・高さはすべて外寸。外周線は内側に含め、影・枠の外側リングは外寸に含めない。本文の幅を求めるときは、左右の線・padding・チップ・gap を外寸から差し引く。`M(text, role)` は下表の書体・サイズ・weight で描いた文字列の実幅。`L` はその内容幅で全文を折り返した行数とする。式による内容幅が0以下、または1文字も置けない幅になる場合も、文字を縮めず「折返し・衝突・収まり」の制約として扱う。

| 用途 | 書体 | size / line-height | weight / 字間 |
| --- | --- | --- | --- |
| 基本文字・入力帯・一覧名 | sans-serif | 15px / 24px | 400 / 0 |
| テストタイトル | sans-serif | 16px / 24px | 600 / 0 |
| 操作 → 期待結果 | sans-serif | 17px / 26px | 600 / 0 |
| 一覧の現在名 | sans-serif | 15px / 24px | 600 / 0 |
| STEP 表示・主注釈のチップ数字 | mono | 14px / 20px | 600 / 0 |
| 一覧のチップ数字 | mono | 14px / 14px | 600 / 0 |
| 枠見出し | sans-serif | 14px / 20px | 600 / 0 |
| キー表示のキー名 | sans-serif | 21px / 30px | 600 / 0 |

sans-serif の書体は `ui-sans-serif, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", "Noto Sans CJK JP", sans-serif`、mono は `ui-monospace, SFMono-Regular, Menlo, Consolas, "Liberation Mono", "Noto Sans Mono CJK JP", monospace`。進行数字・番号の桁は等幅にし、本文中の数値・期待値は本文と同じ書体で保つ。文字は装飾なし。日本語を含む全文の実幅で計算し、半角の文字数だけで幅を決めない。定常表示中の全テキストの不透明度は1。入力帯・キー表示の終了時だけ「入力帯・キー表示の表示時間」のフェードを適用する。省略記号、行数上限による切り落とし、横スクロール、文字サイズの縮小で収めない。空白で折り返し、空白のない URL・期待値・長語は収まる最後の文字境界で折り返す。数値の桁・符号・小数点・通貨記号・単位を削除・置換しない。

`panel-surface`・`surface`・`caption-surface` は背景色だけを下に見えている映像色と合成し、要素全体・文字・子要素は透明化しない。各 RGB 成分について `C = α × 色トークンの RGB + (1 - α) × 背景の RGB` で合成し、`α` は各色トークンの不透明度とする。枠線と内外の対比線も各線の色だけを同じ式で合成する。タイトル帯、チップ面、文字、SVG（カーソルの残像を除く）、パネル・入力帯・キー表示の中立色外周線は不透明。テキスト面を薄くしたり、完了行をさらに低い不透明度にしたりしない。ぼかしがなくても、最も明るい背景と最も暗い背景への合成の両方で、`text`・`secondary`・`accent` の文字用途は4.5:1以上、チップ数字・`on-active`・`done`・`pending-ink` はそれぞれの面に対して4.5:1以上のコントラストを保つ。

対象を透かす `frame-fill` には注釈の文字を置かない。枠は `frame-stroke` の線の内側に1px の `frame-inner-guard`、外側に1px の `frame-outer-guard` を添える。合成後も背景の明度によらず少なくとも一方の対比線が3:1以上で見える。波紋は `accent` の線と不透明色の `ripple-inner-guard`・`ripple-outer-guard` でクリック位置を示し、消失中の不透明度は動きの指定に従う。確認するページ文字には枠内の塗りを重ねても判読性を維持し、変化の細部を隠さない。

#### タイトル帯とステップ進行

タイトル帯は映像最上部、幅 `W`、上下16px・左右24px の padding、`title-surface` 面。`text` 色で左に describe 階層を含むテストタイトル、右に `STEP <番号> / <総数>` と分割進行を置く。タイトルと右領域の間隔は24px。文字は左寄せ、帯の中で縦中央に揃える。

進行の幅 `P = max(160s, (8N - 4)s)`、高さ6px。セグメントは `N` 本、間隔4px、各幅 `(P - 4s(N - 1)) / N`、角丸2px。左から発生順に並べ、未着手は `pending-surface`、現在は `active-fill`、完了は `done-surface` に `done` の1px 内側輪郭を付ける。各セグメントの最小幅は4px。個数を減らしたり連結したりしない。数字と進行の間隔は12px、数字は折り返さない。

`W >= 720s` では右領域幅を `M("STEP N / N", STEP) + 12s + P` とし、タイトル領域幅は `W - 48s - 24s - 右領域幅`。タイトルはこの幅で全文を折り返す。`W < 720s` ではタイトルを全内幅 `W - 48s` の上段、数字と進行を12px 下の下段に左寄せで置く。下段でも数字と進行が並ばなければ進行を8px 下に置く。進行の幅自体が全内幅を超える場合は収まりの制約として報告する。

帯の高さは `max(64s, 32s + 内容の高さ)`。折返しを含めた最大の内容高さを操作前に確定し、全期間で固定する。1280×720px の映像で帯が64px ならページ領域は1280×656px。長いタイトルのため帯を高くする場合もページ映像を遮らず、その分の帯領域を確保する。

#### ステップパネルと全ステップ一覧

パネルは操作 → 期待結果のステップラベル、仕切り線、全ステップ一覧を縦に並べる。独立した状態行は設けず、その文字・記号・高さ・前後の間隔も確保しない。既定はページ映像の左上、上端・左端から `edge`。背景は `panel-surface`、中立色の `surface-line` 外周と `shadow`、角丸 `panel-radius`。全方向の `panel-pad` は枠の内側に取り、文字や数字を面の端に直接置かない。

外幅 `B` と一覧の列数は、次の候補順で選ぶ。各外幅は `min(指定幅, W - 2edge)` とし、同じ外幅・列数の候補は最初の1つだけ残す。採用は「折返し・衝突・収まり」の順に従い、広いパネルも2列も、面全体を保護領域・配置済みの注釈から離して置ける場合だけ使う。

| 優先順 | 指定幅 | 一覧の列数 | 候補に含める条件 |
| --- | --- | --- | --- |
| 1 | 420px | 1 | 常に。既定のコンパクト幅 |
| 2 | 360px | 1 | 常に。対象の左右の狭い空き領域に置く幅 |
| 3 | 560px | 1 | 常に。折返しによる高さを減らす幅 |
| 4 | 720px | 1 | 常に。さらに折返しを減らす幅 |
| 5 | 720px | 2 | `N > 5` かつこの候補の `T >= 600s` |

本文幅 `T = B - 2surface-line - 2panel-pad`。操作 → 期待結果は `T` 幅で全文を折り返す。主注釈の番号をパネルに付ける場合は、ラベルの前に入力帯と同じチップ・12px gap を置き、その番号領域を `T` から引いた幅で折り返す。ラベルの下12px に高さ1px・幅 `T`・`line` 色の仕切り線を引き、その下12px から一覧を開始する。

1列では列幅 `T`、2列では列幅 `(T - column-gap) / 2`。2列の番号順は上段左、上段右、次段左、次段右。各行は左右の列にかかわらず、番号バッジ、名称の順に置く。行間は `row-gap`。

一覧チップの高さは32px、幅 `D = max(32s, 12s + M(N, 一覧のチップ数字))` とし、全行で同じ幅を確保する。角丸は16px、数字は中央に置く。1桁・2桁は円形、桁数が増えたら横長となり数字を縮めない。チップを中央に置く番号バッジ領域は高さ44px・幅 `A = D + 12s` とし、1桁・2桁では44px 四方となる。状態装飾は外側の対比線を除いてこの領域内に置き、装飾の有無で番号・名称の位置を動かさない。

全行の上下左右に8px の padding を取り、名称幅は `列幅 - 16s - A - chip-gap`。番号バッジと名称の間は `chip-gap`。全文をこの幅で折り返し、全件・全状態の名称の最大行数を `Lmax` とする。全行の高さを `max(76s, 16s + max(44s, 24s × Lmax))` に揃え、操作前に確定する。バッジと折返し後の名称全体を行内で縦中央に揃える。折返しで76px を超える場合も全行を同じ高さへ広げ、固定高で文字を切らない。

| 一覧状態 | チップ | 名称 |
| --- | --- | --- |
| 未着手 | `pending-surface` 面、`pending-ink` の1.5px 内側輪郭と数字 | 名称は `secondary`・400 |
| 現在 | `active-fill` 面、`on-active` 数字、輪郭・グローなし | 名称は `text`・600 |
| 完了 | `done-surface` 面、`done` の1.5px 内側輪郭と数字。数字をチェックへ置き換えない | 名称は `secondary`・400。「完了」の文字・領域は設けない |

一覧の状態装飾は「番号バッジの状態装飾」に従う。パネル高さは `2surface-line + 2panel-pad + 操作ラベル高さ + 12s + 1s + 12s + 一覧高さ`。一覧高さは段数と全行共通の行高の積に、段間の `row-gap` の合計を加えた値。全行を同時に映し、パネルをスクロールさせない。短縮名は操作と対象を保って事前に決め、未着手・現在・完了で名称の長さを変えない。長い期待値はステップラベルと結果見出しに全文を残す。収まりは後述の配置規則で判断する。

#### 番号バッジの状態装飾

全ステップ一覧の番号を維持し、現在のステップには「ステップの対応と表示状態」に対応する装飾を1つだけ付ける。未着手は数字だけ、完了済みのステップはチェックを維持する。位置は番号バッジ領域を基準とする。以下の寸法は共通の `icon` 寸法とは別に適用する。

| 装飾 | 寸法・位置・色 | 動き |
| --- | --- | --- |
| 小さなスピナー | 右上端、14px 四方、2px の `accent` 線、右側1/4を透明にした円。`title-surface` 面と外側2px の同色の対比線 | 中心を軸に時計回り、900ms で0度から360度へ等速回転を繰り返す |
| 大きな周囲リング | バッジ領域の各辺から内側1px、高さ42px・幅 `A - 2s`、角丸21px。2px の `accent` 線、右側1/4を透明にし、面なしで数字を囲む | 中心を軸に時計回り、2000ms で0度から360度へ等速回転を繰り返す |
| 完了チェック | 右下端、16px 四方の円、`done` 面、外側2px の `title-surface` 対比線。中央に11px 四方の SVG、`done-surface` 線。`viewBox="0 0 12 12"`、パス `m2 6 2.5 2.5L10 3`、線幅1.7、線端・接合は丸 | 静止 |

#### 対象・結果の枠と見出し

枠は強調する要素の実際の位置・大きさに追従し、その外側2px に `frame-stroke` 色・`frame-line` 幅の実線を置く。角丸は `min(frame-radius, 枠幅 / 2, 枠高さ / 2)`。線の内側の対比線は `frame-inner-guard`、外側は `frame-outer-guard`、内側の塗りは `frame-fill`。映像の境界を越える線だけ境界で切り、対象の見える部分をずらさない。対象が消える場合は消える前の位置と、消えた後の結果や空の領域を示す。

見出しの背景は `caption-surface`、文字と SVG は不透明な `on-active`、角丸 `caption-radius`、上下8px・左右12px の padding。既定は枠の左端から8px、枠の上辺より `protect-gap` 上に下端を置く。見出しを枠や対象の内容に重ねない。主注釈の場合だけ先頭に番号チップ（高さ24px、幅 `max(24s, 8s + M(N, 主注釈のチップ数字))`、角丸12px）を置く。このチップは不透明な `on-active` 面に不透明な `active-fill` 数字。番号、SVG、本文の間は `caption-gap`。

本文は、対象なら `<操作の短語> · <対象名>`、結果なら `確認 · <名前> === <期待する状態・値>`（例: `確認 · Total === ¥3,300`）。`===` は期待値を示す表示上の区切りであり、JavaScript の比較の実行やアサーションの合格を示さない。結果には番号を付けない。見出し外幅は `min(W - 2edge, 24s + 番号領域 + icon + caption-gap + M(本文, 枠見出し))`。番号領域は主注釈なら番号チップ幅と `caption-gap`、それ以外は0。本文だけを残り幅で折り返し、番号と SVG は縮めず、先頭行の中央に揃える。高さは `16s + max(番号チップ高さ, icon, 20s × 本文行数)`、番号がなければ番号チップ高さは0。長い数値・値を切らず、次行は本文の開始位置に揃える。

SVG と短語の対は、クリック: ポインター＋「クリック」、文字入力・値の編集: 鉛筆＋「入力」、キー: キーキャップ＋「キー」、スクロール: 上下矢印＋「スクロール」、hover: ポインター＋「hover」、ドラッグ: 手＋「ドラッグ」、popup・別タブを開く操作: 外向き矢印＋「開く」、結果: 目＋「確認」。「確認」は動画で見る場所でありアサーションの成功判定ではない。操作対象の枠がないときに見出しだけを浮かせず、主注釈の番号を入力帯・キー表示・ステップラベルのいずれかに付ける。

#### カーソル・波紋・入力帯・キー表示

| 要素 | 寸法・面・文字 | 既定位置 |
| --- | --- | --- |
| カーソル | 標準ポインター形状の矢印、16×24px。`cursor-fill` 面、`edge-guard` の1.5px 縁。先端が操作座標 | 実際の操作の軌道に沿う |
| カーソルの残像 | カーソルと同じ形状・寸法・色トークンの半透明な複製。通過時の opacity 0.25から200ms で等速に0へ消す | 実マウスの通過座標に、通過時刻と同期して残す。複製はその位置から動かさない |
| 波紋 | 直径12px から48px へ450ms 等速で拡大し、opacity 0.75から0へ。`accent` の2px 円、内側1px の `ripple-inner-guard`、外側1px の `ripple-outer-guard`、面なし | 実際のクリック位置が中心 |
| 入力帯 | 外幅 `I = min(0.52W, W - 2edge)`、上下12px・左右20px padding、`surface` 面、中立外周と影。高さ `2surface-line + 24s + max(番号高さ, 24s × 文字列行数)`、角丸は高さの半分 | ページ下部中央、下端から `edge` |

入力帯・キー表示が主注釈の場合、見出しと同寸法の番号チップを左端の padding 内側に置き、`active-fill` 面・`on-active` 数字、本文まで12px 空ける。番号領域は番号チップ幅と12px、それ以外は0。番号を除いた本文領域幅は、外幅から左右padding・外周線・番号領域を引いた値。入力帯は `text` の連続した文字列をその領域の中央寄せで折り返す。入力値の更新で幅と下端位置を動かさず、高さだけ上方へ増やす。空文字列では空の24px 行を残し、削除結果を見せる。

キー名は `text`、文字入力以外の実際のキー名（`Tab`、矢印、`Enter`、`Backspace`、`Ctrl+R`、`Alt+←`、プラットフォームに応じた `Meta` 系など）とホイール操作の `ScrollDown` / `ScrollUp` を表示する。キー名を本文領域で中央寄せ・折返しとし、API で代行した操作だけ14px / 20px・`secondary` の「操作案内」を8px 下に添える。その場合のキー本文高さは `30s × キー名行数 + 8s + 20s`、実キーなら `30s × キー名行数`。番号は先頭行の中央に揃える。動きを減らす設定ではカーソルの残像を表示せず、実操作に同期するカーソルと移動・停止の時間は維持する。入力・キー表示のフェードは維持し、波紋は直径24px のまま450ms で消す。

#### 折返し・衝突・収まり

操作対象・確認対象の可視矩形を各方向に `protect-gap` 広げた領域を保護する。枠の薄い塗り・追従するカーソルとその残像・クリックの波紋を除き、注釈の文字・面・外周線をこの領域へ重ねない。ページ本来の要素を移動・隠蔽しない。注釈同士の文字面にも `gap` を取る。重なり順はページ映像、枠と波紋・残像、枠見出し・パネル・入力帯・キー表示、カーソル、タイトル帯の順とする。同じ段でも文字面を重ねない。残像は注釈の文字面に重なる部分を描かず、ページの確認内容の判読性を維持する。

最初に保護領域と、その時点で表示するパネル以外の全注釈の折返し後の寸法を求め、次の順で配置を確定する。

1. 枠は対象の位置のままにする。各見出しを対象の上、下、右、左の順に試す。上・下は対象の左端＋8px に左端を揃え、左右は対象の上端に上端を揃え、対象から `protect-gap` 離す。映像の安全余白に収まるよう対象と平行な方向だけ位置を補正し、保護領域に重ならない最初の位置を選ぶ。操作対象と表示中の確認箇所の見出しを同時に置く場合は、対象の上端、左端の順で配置し、同じ位置なら操作対象、結果の順とする。
2. ステップパネルは「ステップパネルと全ステップ一覧」の候補順で試す。各候補の幅・列数を先に固定し、主注釈の番号領域を含むラベルと、全件の名称をその内容幅で折り返して高さを計算する。状態で名称の weight が変わる場合は最大の行数を使う。内容幅が成立しない、または面全体が安全余白内の幅・高さを超える候補は飛ばす。成立しうる候補について、安全余白の左上、右上、左下、右下の順に置き、保護領域・見出しと最小間隔を守れる最初の位置で幅・列数・高さ・位置を確定する。4隅とも不成立のときだけ次の幅・列数へ進む。位置ごとに幅を変えたり、配置後に列数や高さを決め直したりしない。
3. 入力帯は下部中央、上部中央、左端中央、右端中央の順に試す。キー表示は中央、下部中央、上部中央、左端中央、右端中央の順に試す。いずれも安全余白内に置き、保護領域と配置済みの文字面に重ならない最初の位置を選ぶ。

折返し後の面全体が `W - 2edge`・`H - 2edge` に収まることを必要条件とする。全件の番号と短縮名、現在の操作と期待値、主注釈の番号を常に保ち、結果見出しは表示中の1箇所の全文を保つ。対象の位置や注釈内容・高さが変わったら、初回と同じ候補順・配置順で再配置する。後続の入力帯・キー表示を置けない場合も、確定済みの見出し・パネルへ戻って候補を選び直さず、下記の制約として扱う。テーマだけの変更では位置・幅・高さを変えない。

どの候補も成立しない場合は、全件表示と確認箇所の視認を両立できない対象・ステップ数・値・映像寸法を録画の制約として報告する。隠す・省略する・小さくする・勝手に別の注釈を増やすことで適合したことにしない。背景追従や配置の都合でサイトの遷移・状態更新を遅延させたり、実操作と違う時間軸にしたりしない。

### 背景と注釈テーマの追従

サイトの main 背景は、現在映しているページの主要コンテンツ面の背景であり、OS の設定・テーマ名・操作中の要素の色ではない。主要領域はサイトが main ランドマークとして示す領域とする。可視の main ランドマークが複数あれば、映像内の可視面積が最大の領域を使う。同面積なら上端が小さいもの、次に左端が小さいものを選ぶ。main ランドマークがなければページ映像全体を使い、見た目から別の領域を任意に選ばない。iframe 内を操作していてもページ全体を映す間はページの主要領域を使い、frame だけを映す場面ではその映像の主要領域を使う。

選んだ領域の映像内にある部分の最小外接矩形を横5・縦5に等分し、各セルの中心25点で背景色を観測する。対象は文字・ボタン・カード・注釈などの前景を重ねる前の主要面の色。透明な主要面は祖先の背景・画像・グラデーションを奥から合成し、最後はページのキャンバス色へ合成する。ページのキャンバスも透明ならブラウザーの白いキャンバスへ合成する。各背景色は sRGB に揃え、成分を0から1の範囲へ収める。透明度αの各層を奥から `C = α × 手前のRGB + (1 - α) × 奥のRGB` で合成する。背景画像・グラデーションは各点の実色を使う。可視領域の外の点は除外し、有効点が13点未満ならページ映像全体の25点で同じ観測を行う。前景の占有率、注釈自身の色、マウス位置で分類を変えない。

各点の合成後の sRGB 成分を0から1へ正規化する。成分 `c <= 0.04045` は `c / 12.92`、それ以外は `((c + 0.055) / 1.055)^2.4` に変換し、輝度 `Y = 0.2126R + 0.7152G + 0.0722B` を得る。有効点の `Y` の中央値を main 背景の輝度とする。偶数点なら中央2点の平均を使う。

| 観測時点・条件 | 注釈のテーマ |
| --- | --- |
| 最初の主要面、または遷移・リロード・別タブ・映像のページ切替後の新しい主要面で `Y <= 0.179` | dark サイトと分類し、light 注釈 |
| 同じ初回条件で `Y > 0.179` | light サイトと分類し、dark 注釈 |
| 同一ページで light 注釈を使い、`Y >= 0.21` が100ms 以上続く | light サイトへ変わったと分類し、dark 注釈へ切替 |
| 同一ページで dark 注釈を使い、`Y <= 0.15` が100ms 以上続く | dark サイトへ変わったと分類し、light 注釈へ切替 |
| 同一ページで上の切替条件を満たさない | 現在の注釈テーマを維持 |

最初の注釈を出す前に初回分類する。以後、背景の観測間隔は50ms 以下とし、同一ページの切替は100ms 以上離れた2回の観測で同じ条件を満たして確定する。背景が条件を満たし続けた最初の映像時点から250ms 以内に全注釈を切り替える。main 背景のテーマ切替、画像やグラデーションの変化、主要領域の交替を含み、ステップの終わりを待たない。100ms 未満の一時的な明滅では切り替えない。

遷移等で旧主要面が消え、新主要面がまだない区間は旧テーマとステップラベルを維持する。main ランドマークもサイト本来の可視内容もない白紙を、主要面がまだない区間とする。新主要面が映ったら初回閾値で再分類し、その最初の映像時点から100ms 以内に全注釈へ適用する。主要面がない白紙のまま250ms 続く場合はページ全体を主要面として再分類する。主要面の新設・交替は、同一ページなら継続観測の切替条件、ページ切替なら初回条件を使う。

切替は同じ映像フレームでタイトル・パネル・進行・枠・見出し・チップ・バッジ装飾・SVG・カーソル・残像・波紋・入力帯・キー表示の全トークンへ適用する。新旧テーマを混ぜず、クロスフェードしない。表示中の入力や波紋・残像も追従し、番号・名称・状態・値・位置・操作の時間や残像の通過時刻をリセットしない。追従できない区間は制約として報告し、ステップ中固定のテーマで代用しない。

### 入力帯・キー表示の表示時間

入力帯は最後のキー入力（keydown がない場合は値の更新）による更新から600ms 後に全体を300ms でフェードして消す。Backspace 直後の文字入力では、削除結果が見えるまで最大160ms 表示を遅らせる。キー表示は操作の間維持し、最後の操作から600ms 後に全体を300ms でフェードして消す。操作と同期する内容は「実操作と同期」に従う。

| popup・別タブ・iframe | 開く操作の共通注釈と、移動先のページ・frame に再設置した注釈 |

### 時間の間隔

ステップ間の間隔は、視聴者が操作を予測してから結果を読み終えるまでの最低時間で担保する。各ステップは文書内の状態に応じた指定時間を満たし、時間は注釈の動きではなく動画の経過時間で測る。

- 操作待ち: 対象の可視化・操作可能性など操作前の準備を終え、ステップラベル・操作対象の注釈（枠がない操作では規定の主注釈）がすべて実際に映った時点から、操作開始まで固定 1.2 秒を設ける。番号が数字だけの状態でもこの固定時間を維持する。準備や描画待ちの時間を含めず、sleep の指定時間だけで満たしたことにしない
- 操作中: カーソル移動は 1 回を最低 300ms かけ、クリックの前にカーソルを対象の上へ最低 200ms 止め、最後の移動から200ms で残像が消えてからクリックする。残像の消失時間は移動時間ではない。文字入力は 1 文字ごとに 80ms 以上空ける。`fill()` など keydown なしで瞬時に完了する代行操作は、入力帯の文字列と対象の枠を最低 600ms 表示してから結果の確認へ移る
- 確認待ち: 操作終了から最初の確認枠と見出しを表示するまで最低 0.5 秒空け、確認対象の出現と描画の安定も待つ。待機中にページ本来の状態更新や番号を囲む確認待ちリングの表示・動きを遅らせない
- 結果表示: 各確認箇所の枠・見出し・確認する内容が実際に映った時点から、1箇所ごとに最低 2 秒維持する。値・文字列を読む箇所は最低 3 秒。前の確認枠と見出しを消してから次の確認枠と見出しを出すまで 0.5 秒空ける。全箇所の表示時間と切替間隔を満たし、最後の箇所の表示時間も終えてから次のステップの操作待ちへ移る
- 動画の終了: 最後のステップでも全確認箇所の表示時間と切替間隔を満たし、最後の箇所の表示時間を終えてから録画を確定させる

遷移・リロード・別タブを挟むステップでは、移動先の描画が落ち着いてから結果の確認へ移り、各確認箇所の表示時間を改めて満たす。操作待ちの固定時間と、読み込みや確認対象の出現までの自然な待機を区別し、自然な待機は短縮・省略しない。結果表示の時間は下限とし、自然に長くなる分は詰めない。追加した待機の合計がランナーのタイムアウトを超えないよう、録画ケースのタイムアウトを確認する。

### 実操作と同期

カーソル移動は `ease-in-out`（`cubic-bezier(0.42, 0, 0.58, 1)`）で開始時に加速し、終了時に減速する。実マウス座標とカーソル先端を同じ進捗・時刻に揃え、途中の移動イベントを実時間で発生させる。残像は同じ座標・時刻の移動履歴を示し、別の軌道や遅れて動く実カーソルで代用しない。カーソルが対象に着いた後の停止と残像の消失は「時間の間隔」に従ってからクリックする。`scrollIntoViewIfNeeded()` による瞬間移動だけで画面外のクリック対象を見せたことにしない。スクロールでは、シナリオの挙動を変えずに済む場合は長い移動を小刻みな wheel 操作にし、画面外の対象へは先に滑らかに移動してから操作する。スクロールによる遅延読込などで検証対象の挙動が変わる場合は元の操作を維持し、移動をラベルと画面上の到着位置で補う。装飾は録画中の DOM オーバーレイで操作・変化と同期させる。後処理で加える表現も、元の映像と時刻が一致する場合に限る。局所拡大、静止保持、停止中のカーソルの非表示は、既にある映像と注釈の見せ方を変える範囲で読みやすさの補助として選べる。ただし、実際の移動・待機・失敗を消したり、保持を実際の表示時間と混同させたりしない。

キー表示は画面上の入力文字列と区別し、実際の操作に対応させる。フォーム送信を `Enter` で行う場合は送信前に `Enter` を表示し、クリック送信ならボタンへのカーソル移動と波紋で示す。ブラウザー側の `Ctrl+R` や `Alt+←` が Playwright のキー送出では動作しない場合は、キー表示に「操作案内」と明記してから `page.reload()` / `page.goBack()` を呼ぶ。実キー入力時のキー表示と API による代行を区別し、キーを押したと偽らない。キー入力を伴わない操作もステップラベルと対象・結果の枠で示し、視覚表現のない操作を残さない。

入力中の文字は一つの連続した文字列として表示する。`Ctrl + A` / `Meta + A` は帯を操作名に置き換え、続く文字入力は新しい文字列として表示し、Backspace では削除後の文字列に更新する。`locator.fill()` のように keydown なしで文字入力対象に `input` が起きた場合は、その対象の値を表示する。checkbox など文字入力対象でない要素の `input` は帯に値を出さず、対象の枠と状態変化で示す。文字が順に増える様子で入力を示すため、録画ケースの文字入力は操作の意味が変わらない限り `pressSequentially()` で 1 文字ずつ行い、`fill()` などの一括設定で映す箇所を作らない。長い値などで 1 文字ずつが現実的でない場合だけ一括設定を使い、その箇所と理由を報告する。

装飾は DOM に要素を追加する。スクリーンショット比較や全要素数を調べるアサーションには影響しうるため、その間だけ装飾を隠すなどして期待値とテストの意味を維持し、装飾なしの結果とも照合する。維持できなければ録画の制約として報告し、合否が変わらないとは主張しない。ポップアップ、複数ページ、iframe 内の操作では、装飾するページと動画の選択を調整する。ページ映像の切り替えでは URL の露出を確認し、フォーカス先の強調は `activeElement` や DOM 装飾だけで正しいと断定せず映像と照合する。画面外のアサーションやネットワーク結果を画面上の成功表示と混同しない。

## 確認と報告

録画ケースの操作と確認する画面変化を列挙し、各々について操作前から結果の確認まで途切れないラベル、対象の強調、操作の視覚表現、結果箇所の強調が最終 MP4 の連続フレームで追えるかを照合し、各ステップが「時間の間隔」の指定を満たすか、操作待ちの準備完了と必要な注釈が映った時点からの固定時間、操作中の最低時間、操作終了から最初の確認枠・見出しまでの最低間隔、各確認箇所の表示時間、前の確認枠・見出しの消失から次の表示までの切替間隔を経過時間で確認する。操作待ちが数字だけでも固定 1.2 秒を満たすこと、一覧の番号が全状態で維持され、「番号バッジの状態装飾」の形状・回転・動きを減らす設定が状態と対応すること、独立状態行がなく操作ラベルが保たれること、確認枠・見出しが1箇所ずつ映ること、次ステップや録画終了が最後の箇所の表示時間を短縮していないことも照合する。対応するフレームが欠けるときは録画ケースや装飾を修正して再録画し、なお見せられない操作・変化は対象と制約を報告して、視覚的に網羅できたとは主張しない。タイトル帯のタイトルが読めるか、カーソルの中間位置と開始時の加速・終了時の減速、実移動と同期した通過位置の残像と最後の移動から200ms 後の消失・クリック前の停止、ステップパネル背景の透けと不透明な文字・チップ、拡大する波紋、入力帯への連続した文字入力と帯全体のフェードが確認できるか、失敗したテストも録画されたかを確認する。ショートカット、Backspace、keydown なしの文字入力、非文字入力対象の操作を含む場合は、キー表示・文字列の更新と、非文字入力の値が帯に出ないことも確認する。残像の背景追従と注釈の保護配置、動きを減らす設定での残像の無表示も照合する。短時間の表示は該当区間を高頻度でフレーム抽出して確認し、粗い間隔の抽出だけで表示がなかったと断定しない。`ffprobe` で動画の映像コーデックと再生時間を確認し、各録画ケースの最終試行の MP4 を1本ずつ再生して開始から終了まで照合する。各録画ケース・対象の主要なウェブ使用フロー・動画のパス・アサーションを含む自動テスト結果を対応付けて報告し、通常の E2E の実行結果と録画ケースの実行結果、動画に対する人手の go/no-go 判断を区別する。映像だけでは判断できない点も報告する。

録画の組み込み・再調整では、実装の DOM オーバーレイと動画の後処理、および各最終 MP4 に現れる録画処理由来の表示を列挙し、共通注釈、既にある映像と注釈の見せ方を変えるだけの補助、ユーザーが承認したプロジェクト固有の表示のいずれかに対応付ける。全表示の対応先を示せたときに適合を報告する。対応先が定まらない表示は余剰であり、実装から取り除いて再録画するか、ユーザーの承認を得てプロジェクト固有の表示として確定してから判定する。

動画レビューまで依頼された場合は、失敗テストを先に確認し、指摘には動画パス、経過時間、見えた事実を添える。失敗と判定できない見た目は観測として区別し、動画を見ただけでテストのアサーションが成功したと結論しない。
