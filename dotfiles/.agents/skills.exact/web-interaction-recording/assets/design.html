録画注釈のデザイン確認ギャラリー

上から「操作前 → 操作中 → 確認待ち → 結果表示」の順に読む。左が明るいサイト、右が暗いサイトで、それぞれ同じ注釈を当てた例。 設定操作は不要。

タイトル帯・task label はサイトと同じ明暗、入力帯・キー表示（dock）はサイトと逆の明暗。 進行は READ 表示で、結果の閲覧が済むごとに進む。

表示値はデザイン検査用の見本。実際の録画やテストの合格を表さない。

映像領域は1280×720（タイトル帯以外）で固定。外側だけ縮小表示する。「1:1で見る」で原寸に切り替えられる。

補助例を見る — 入力・キー・長文・配置制約・外タイトルなど

主8例と同じ描画実装による追加の見本。配置制約の例は、収まらない注釈を省略せず表示する。
