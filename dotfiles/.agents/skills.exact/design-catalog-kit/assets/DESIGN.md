## 1. 視覚方針

涼しい側へ寄せたグレーによる朝霧のようなトーン（cool-mist）を基調とする。丸みのある柔らかい面、低めのコントラスト、繊細な影で構成し、比較領域を主役とする。操作部は小さな文字と無彩色の面で構成する。装飾画像、グラデーション、ブランド的な大見出しを使わない。各案の色・書体・背景は案HTMLが所有し、viewerのトークンをiframe内へ適用しない。

グレーは彩度を抑え、明度差だけで階調を作る。色を持つのはキーボードfocusの `--focus` だけである。

## 3. 文字

UI書体は `system-ui, -apple-system, "Segoe UI", sans-serif`。数値にも同じ書体を使う。外部フォントを読み込まない。

| 用途 | サイズ / 行高 | weight |
| --- | --- | --- |
| カタログタイトル | `26px / 34px` | `600` |
| 軸見出し | `21px / 29px` | `600` |
| 軸番号バッジ | `17px / 1` | `600` |
| 本文・軸・案の説明 | `17px / 26px` | `400` |
| 案ラベル | `17px / 25px` | `600` |
| ボタン（Replay以外の規定値） | `16px / 24px` | `600` |
| 記号バッジ | `15px / 1` | `600` |
| Replay | `15px / 22px` | `600` |

字間は通常値。タイトル・軸ラベル・説明・案ラベルは折り返し、空白のない長い文字列も領域内で改行する。説明の最大行幅は `80ch`。意味を隠す省略や行数制限は使わない。

## 4. 配置・responsive・スクロール

間隔トークンは `--space-1: 4px`、`--space-2: 8px`、`--space-3: 12px`、`--space-4: 16px`、`--space-5: 20px`、`--space-6: 24px`、`--space-8: 32px`、`--space-10: 40px`。

viewerは通常の文書フローで、内容幅の上限は `1600px`、中央寄せ。縦方向はviewer文書がスクロールを所有する。ヘッダーや操作部を固定・重ね表示しない。viewer本体に横スクロールを作らない。

上から、カタログヘッダー、軸セクションの順に並べる。軸セクションは見出し部（軸番号バッジ・軸ラベル・軸の説明）と、その軸の全案を横1行に並べた案行で構成する。DOM順と見た目の順を一致させる。

| viewerの幅 | 外周余白 | ヘッダーと軸領域の間隔 | 軸セクション間隔 | 見出し部と案行の間隔 | 案の列間隔 |
| --- | --- | --- | --- | --- | --- |
| `768px`以上 | `24px` | `32px` | `40px` | `20px` | `16px` |
| `768px`未満 | `20px` | `24px` | `24px` | `16px` | `12px` |

### 案の行とカードの幾何

| 項目 | 定義 |
| --- | --- |
| 軸の案行 | 全案を1行のflex行に並べる。収まらない分はその行だけ `overflow-x: auto` で横スクロールし、他軸のスクロール位置に影響しない。縮尺で代用しない |
| カード幅 | 全案共通の `clamp(320px, 30vw, 480px)` |
| カードの高さ | 同じ行の全案で等しい |
| caption | iframeの上に置く。上段は記号バッジ・案ラベルとReplayを左右両端へ、下段は違いの説明 |
| iframeの上端 | 説明の長さに依存せず軸内の全案で揃う。previewをカードの下端へ揃え、iframeの高さを全案で同じにすることで実現する |
| captionとiframeの間 | 説明が短いほど広がる |
| iframe | 幅はカードの内幅いっぱい、高さは `640px`。拡大縮小せず、左上を基準に置く |
| 案内部のスクロール | iframe内の文書が所有する |

## 5. 操作部と状態

Replayの最小高さは `34px`、左右paddingは `16px`。captionの行末とReplayの間は `8px`。アイコンだけの操作を設けない。

| 部品 | 構造・表示 |
| --- | --- |
| カタログヘッダー | カタログタイトルのみ |
| 軸見出し部 | 軸番号バッジと軸ラベルを横に並べた行、下に軸の説明 |
| 軸番号バッジ | `26×26px`、角丸 `9px`、`--current` の面に `--ink` の数字。軸の並び順に `1, 2, …` を振る |
| 記号バッジ | 高さ `22px`・最小幅 `22px`、角丸 `7px`、`--current` の面に `--ink` の英字。案の並び順に `a, b, c, …` を振る |
| 案ラベル | 記号バッジの右 |
| 違いの説明 | captionの下段、`--muted` |
| Replay | 各案のcaption右上のpill。表示は `Replay`、名前は `Replay <軸ラベル> · <案ラベル>` |

| 状態 | 視覚表現 |
| --- | --- |
| 通常 | Replayは `--current` の面、`--ink` の文字、`--control-line` の1px境界 |
| hover | 操作可能な要素だけ `--hover` |
| 押下中 | `--pressed`。位置・大きさは変えない |
| focus-visible | `--focus` の2px輪郭、外側2px。hover・押下と同時に見える |

## 6. 動きと操作フィードバック

viewer自身の状態変化は即時、durationは `0ms`。hover・focus・テーマ変更で移動、拡縮、点滅、フェードを加えない。通常設定とreduced motion設定でviewerの見た目は同じである。

案内のアニメーションとその操作手順は、各案の違いの説明で読める形にする。

## 7. 面・境界・角丸

深度は面の濃淡、`--soft-ring` の内側1px細線、`--shadow-card` の柔らかい影で表す。

| 部位 | 定義 |
| --- | --- |
| 案カード | 境界線なし。`--surface` の面、角丸 `18px`（`768px`未満は `16px`）、`--shadow-card` |
| preview外枠 | `--stage` の面、角丸 `12px`（`768px`未満は `10px`）、内側に `--soft-ring` の1px細線。`overflow: hidden` で案の矩形を角丸へ収める |
| Replay | 角丸 `999px`（pill） |
| バッジ | 軸番号 `9px`、記号 `7px` |

## 8. アクセス制約とaccepted debt

viewer操作部はWCAG 2.2 AAを目標とする。通常文字は4.5:1以上、focusの識別は3:1以上を目安にし、後述の承認済み負債を除く。キーボードfocusを隠さず、ネイティブbuttonを用いる。

各iframeに `軸ラベル · 案ラベル` の名前を付ける。各軸の案行は `group` のrole、`<軸ラベル> options` のラベル、tabIndex `0` を持ち、ArrowLeft / ArrowRight / Home / Endでその行だけを横スクロールできる。Replayはbuttonとしてfocus・実行できる。

文字200%拡大と幅320pxでも、viewerのラベル・説明・操作は折り返して読み取れる。フォーム・キーボード操作・コントラスト・reduced motionの案内部の品質は、案HTMLの所有者が担う。

以下の負債は承認済みの許容範囲である。

| 場所 | 影響と許容範囲 | 所有者・解消条件 |
| --- | --- | --- |
| ライト表示の軸の説明 | `--muted` と `--canvas` の对比は `4.38:1` で、本文の4.5:1基準を僅かに下回る。cool-mistの低コントラスト基調を優先する。案の説明は `--surface` 上で `4.69:1` を満たす | viewer所有者。配色基準の改定時に濃度を戻す |
| Replayの境界 | `--control-line` は面との对比で3:1を下回る。面・影・ラベルで操作部を識別する | viewer所有者。対応環境で操作が識別不能になる場合は受容せず解消 |
| ネイティブscrollbar | OS・ブラウザーごとに寸法や見た目が異なる。ラベル・操作・focusの利用可能性を維持した差は許容する | viewer所有者。対応環境で操作不能・focus不可になる差は受容せず解消 |
