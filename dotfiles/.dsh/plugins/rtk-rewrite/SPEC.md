# rtk-rewrite

## 目的

bash コマンドを実行前に `rtk rewrite` で書き換え、読み取り系コマンドを rtk のコンパクトな出力ラッパー経由にしてトークンを節約する。書き換え規則の本体は `rtk` CLI にあり、本 plugin は書き換えの委譲のみを行う。

## 適用範囲

dsh が `ctx.shell` 経由で実行する全コマンドに効く。bash tool の foreground 実行と background 実行、および plugin など executor を直接呼ぶ Consumer からの実行を含む。

model へ渡る tool 引数と UI の transcript は常に元のコマンドを示す。書き換えで変わるのは実際に実行されるコマンドだけであり、書き換えの事実はログでのみ追跡できる。

## 書き換え

mount 時に `rtk --version` を 1 回だけ調べ、書き換えの可否を判定する。コマンドごとの振る舞いは次の表のとおり。

| 条件 | 実行されるコマンド |
| --- | --- |
| 書き換え無効の状態（下の表）でない、かつ `rtk rewrite` が書き換え後のコマンドを stdout に返した（exit 0 または 3） | 書き換え後のコマンド |
| `rtk rewrite` が exit 1（相当する書き換えなし）を返した | 元のコマンド |
| `rtk rewrite` が書き換え後のコマンドを返したが、空または元と同一だった | 元のコマンド |
| `rtk rewrite` が 2 秒以内に応答しなかった、異常終了した、存在しなかった | 元のコマンド |
| コマンドが `rtk ` で始まる | 元のコマンド（書き換えを試みない） |
| `RTK_DISABLED` 環境変数が `1` | 元のコマンド（書き換えを試みない） |

mount 時のバージョン判定で書き換えが無効化される条件は次のとおり。この間もコマンド実行自体は通常どおり行う。

| mount 時の状態 | 書き換え |
| --- | --- |
| `rtk` バイナリが `PATH` に存在しない | 全コマンドで無効 |
| `rtk --version` が 0.23.0 未満のバージョンを示した | 全コマンドで無効 |
| バージョン文字列からバージョンを判定できなかった | 有効 |
| 上記以外 | 有効 |

書き換えが起きたとき、`bash-rtk` logger に info で書き換え前後のコマンドを残す。

## コマンド実行そのもの

書き換えはコマンド実行の成否に影響しない。書き換えの失敗・無効化によってコマンド実行を失敗させず、sandbox の適用、タイムアウト、出力上限、結果の分類を含む実行の振る舞いは本家 bash-sandbox executor と同一である。

## プロファイルへの組み込み

設定ファイルは設けない。無効化は profile の bundles から本 plugin を除外することで行う。executor の設定（timeoutMs 等）は本家 bash-sandbox executor と同じ形式を受け付ける。

| プラットフォーム | 挙動 |
| --- | --- |
| POSIX | 本 plugin が `ctx.shell` を担う（本家 bash-sandbox executor を差し替える） |
| Windows | 本 plugin は mount されず、本家の pwsh executor が担う |
