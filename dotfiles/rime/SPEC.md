# Kagiroi 日本語入力

対象は、Windows の Weasel と Linux の fcitx5-rime から共通の Kagiroi 日本語変換を使う Rime ユーザー設定である。設定ファイルは dotfiles で管理し、Windows と Linux の各 Rime ユーザーデータディレクトリへ配置する。Kagiroi のスキーマ、辞書、Lua プラグインが利用可能な環境を前提とする。

## 変換

Rime の選択スキーマは Kagiroi とする。ローマ字からかなへの変換は Kagiroi 標準のローマ字 processor（Lua の kana speller と script_translator）の仕組みに従い、対応表は「ローマ字表」節のとおりとする。連続する `n` の入力には次節の過不足補完を挟む。編集中の読みは、漢字変換が確定する前のローマ字入力の結果として表示されるかなである。変換候補には、編集中の読みと一致する語と、読みから変換できる辞書語が含まれる。

| 編集中の読み | 変換候補に含まれる文字列 |
| --- | --- |
| `かんじ` | `かんじ`、`漢字`、`感じ` のいずれか |
| `かな` | `かな` |

数字・記号・句読点・半角アルファベットも変換対象とする。英数字の基本的な文字種候補には、元の表記、全角・半角の表記、アルファベットの大文字・小文字の表記を含める。かなと英数字が混在する文字列の区切りや変換対象は、既存の変換処理に従う。

選択して確定した変換候補はユーザー辞書に記録し、同じ読みの変換では選択した回数に応じて上位の候補として表示する。

## n の過不足補完

連続する `n` を含む入力は、次のように補正する。ペアの変換と不足の補完は入力中と変換時に行い、過剰の補正は変換時にのみ行う。

- ペア: `n` が2個連続したとき、2個目の `n` の打鍵で `nn` を「ん」として消費し、即座に「ん」と表示する。後続の母音や `y` に、消費した `n` を補わない。
- 不足:「ん」になるべき `n` が1個のとき、`n` を「ん」として扱う。入力中は `n` の直後に子音が来たとき(`kanji` は `かんじ` と表示される)、変換時は末尾の `n` に対して(`kan` は `かん` で変換される)。`y` が続く場合は「ん」にせず、`nya` は `にゃ` と表示される。
- 過剰: 編集中の読みに「ん」が連続しているとき(日本語の語に「んん」という連続は存在しない)。変換時に連続する「ん」を1つに畳む。余った「ん」は、直後に母音(`a` `i` `u` `e` `o` `y`)が続くとき、次の音節の頭の `n` としてその母音と結合する。

| 入力 | 入力中の表示 | Space で変換するときの読み |
| --- | --- | --- |
| `nn` | `ん` | `ん` |
| `gennin` | `げんいn` | `げんいん` |
| `nnin` | `んいn` | `んいん` |
| `kan` | `かn` | `かん` |
| `kann` | `かん` | `かん` |
| `nna`、`nnyo` | `んあ`、`んよ` | `んあ`、`んよ` |
| `kanji` | `かんじ` | `かんじ` |
| `kanda`、`kannda` | `かんだ` | `かんだ` |
| `kana`、`nya` | `かな`、`にゃ` | `かな`、`にゃ` |
| `kanna` | `かんあ` | `かんあ` |
| `kannna` | `かんな` | `かんな` |
| `kannnna` | `かんんあ` | `かんな` |
| `konnnitiha` | `こんにちは` | `こんにちは` |
| `kannnji` | `かんんじ` | `かんじ` |
| `kannnen` | `かんねn` | `かんねん` |
| `kannnnen` | `かんんえn` | `かんねん` |
| `nwa`、`nwi`、`nwe`、`nwo` | `んわ`、`んうぃ`、`んうぇ`、`んを` | `んわ`、`んうぃ`、`んうぇ`、`んを` |

## Windows / Linux 共通の操作と候補表示

Windows の Weasel と Linux の fcitx5-rime で Kagiroi を使用するときの操作と候補表示を、モードと日本語入力の状態に分けて定める。モードは日本語入力、半角英数入力モード、IME OFF の3つである。半角英数入力モードは、IME ON のまま未確定の文字列として半角英数を出力・編集するモードである。IME OFF は未確定の文字列を作らず、半角文字をアプリへ直接入力する状態である。Windows の Weasel では、入力状態の通知とトレイアイコンを表示しない。

### モード

`Zenkaku_Hankaku` は、日本語入力中に未確定の文字列があれば半角英数入力モードへ、なければ IME OFF へ切り替える。`Muhenkan`（無変換キー）は、日本語入力中に未確定の文字列があれば半角英数入力モードへ、なければ IME OFF へ切り替える。どちらのキーでも、切り替えで未確定の文字列を確定しない。半角英数入力モードへの入り方は2通りあり、入り方で後続の遷移が異なる。日本語入力へ戻ると、半角英数入力モードで加えた半角英字・数字・記号を保持したまま、続くローマ字入力をかなに変換する。

- `Zenkaku_Hankaku`・`Muhenkan` で入った場合: Backspace または Esc で未確定の文字列が空になったとき、IME OFF へ移る
- Shift+アルファベットキーで切り替わった場合: Backspace または Esc で未確定の文字列が空になったとき、日本語入力へ戻る

半角英数入力モードのキー操作は、次のとおりである。Shift+アルファベットキーによる開始・切替では、押した半角大文字を未確定の文字列に加える。

| キー | 動作 |
| --- | --- |
| アルファベットキー・数字・テンキー・記号・句読点 | 半角文字を未確定の文字列の末尾に加える |
| `Space` | 半角空白を未確定の文字列の末尾に加える |
| `Zenkaku_Hankaku` | 未確定の文字列を保持したまま、日本語入力へ戻る |
| `Enter` | 未確定の文字列をまとめて確定し、日本語入力へ戻る |
| `Backspace` | 末尾の1文字を削る。空になったときは、入り方に応じて IME OFF または日本語入力へ移る |
| `Esc` | 未確定の文字列をすべて削除する。空になったときは `Backspace` と同じ |

IME OFF 中は、非修飾キー押下の `Zenkaku_Hankaku` で日本語入力へ戻る。キー release と修飾キー付きの `Zenkaku_Hankaku` は切り替えない。それ以外のキー（`Muhenkan` を含む）は、従来どおり半角文字をアプリへ直接入力するか、通常の frontend 動作に従う。

### 文節操作

#### 自動分割

文節は、連続する読みの区間を単位とする変換対象である。変換前の最初の `Space` で、「n の過不足補完」節に従って補完した全読みを辞書と連接評価によって文節に自動分割する。全文節の第一候補をまとめて未確定の文字列として表示し、先頭文節を選択対象にする。辞書候補がない文節は、その文節の読みを唯一の候補として扱う。

`きょうはかれー` は `きょうは|かれー` の2文節に分割する。各第一候補が「今日は」「カレー」の場合、表示文字列は「今日はカレー」となる。`|` はこの文書で文節境界を示す表記である。他の読みの境界は辞書・連接評価・学習に応じて決まり、利用者は境界伸縮で調整できる。

#### 文節選択

変換済みと候補一覧表示中の `Left`・`Right` は、選択対象を前・次の文節へ移す。先頭での `Left` と末尾での `Right` は現在の文節を保つ。移動では全文節を未確定のまま保ち、各文節の選択候補と候補一覧の表示状態を保持する。候補一覧表示中に移動すると、移動先の文節の候補一覧を表示する。

候補一覧は選択対象の文節の候補だけを表示する。`Space`、`Up`・`Down`、ページ移動などの候補操作は、選択対象の文節にだけ作用し、他の文節の選択候補を保持する。

#### 境界伸縮

変換済みと候補一覧表示中の `Shift+Left` は選択対象の文節を短くし、`Shift+Right` は長くする。文節の末尾境界を読みの1文字単位で動かす。この節の1文字は Unicode コードポイント1個であり、小書きかな、長音符、英字、数字、記号も各1文字として数える。

| 操作と条件 | 読みの区間の変化 |
| --- | --- |
| `Shift+Left`、読みが2文字以上で次文節がある | 対象文節の末尾1文字を、次文節の先頭へ移す |
| `Shift+Left`、読みが2文字以上で最後の文節 | 末尾1文字を切り出して新しい次文節にする |
| `Shift+Left`、読みが1文字 | 現在の境界を保つ |
| `Shift+Right`、次文節がある | 次文節の先頭1文字を対象文節の末尾へ取り込む。次文節が空になれば、その文節を除く |
| `Shift+Right`、最後の文節 | 現在の境界を保つ |

境界を動かすと、読みが変わった両側の文節を第一候補へ再変換する。対象文節は同じ文節を保ち、読みが変わらない文節の境界と選択候補を保持する。候補がない場合の表示は「自動分割」節に従う。操作前の候補一覧の開閉と展開状態を保ち、一覧が開いていれば対象文節の新しい第一候補を選択して表示する。

### 日本語入力の状態

日本語入力中のキー操作は、未入力、変換前、変換済み、候補一覧表示中の各状態に分けて定める。日本語入力中の `Space` と `Henkan` は、未確定の文字列を確定せずに変換する。テンキーの Enter（Windows の拡張 `VK_RETURN` / Linux の `KP_Enter`）は `Enter` と同じ動作をする。入力開始から候補一覧を表示しない。確定して次の入力を始めると、再び候補一覧を表示しない。`Space` または `Henkan` で候補へ変換した未確定状態を変換モードと呼ぶ。

テンキーのキー名は Windows / Linux の順で併記する。Linux 側の `KP_*` は、Windows の Rime 内部でも使う共通キー名である。

#### 未入力

未確定の文字列がない状態。

| キー | 動作 |
| --- | --- |
| `Space` | 全角空白 `　` を即確定で入力する |
| アルファベットキー | ローマ字からかなへの入力を始める |
| Shift+アルファベットキー | 半角英数入力モードで入力を始める |
| 数字キー | 全角 `０`〜`９` を新たな未確定の文字列に加える |
| テンキー（数字: `VK_NUMPAD0`〜`VK_NUMPAD9` / `KP_0`〜`KP_9`、小数点: `VK_DECIMAL` / `KP_Decimal`、カンマ: `VK_SEPARATOR` / `KP_Separator`） | 数字は半角 `0`〜`9`、小数点は `．`、カンマは `，` を新たな未確定の文字列に加える |
| 記号キー | 記号表の文字を新たな未確定の文字列に加える |
| 句読点（`,`・`.`） | `、`・`。` を新たな未確定の文字列に加える |

#### 変換前

候補への変換前の未確定の文字列がある状態。

| キー | 動作 |
| --- | --- |
| `Space` | 「自動分割」節の文節変換を行い、変換済みへ移る |
| `Henkan` | 読み全体を1文節として扱い、その第一候補をカタカナにして変換済みへ移る |
| `Enter` | 未確定の文字列を確定する |
| アルファベットキー | 押したキーをローマ字からかなへの入力に使う |
| Shift+アルファベットキー | 半角英数入力モードへ切り替えて、未確定文字列の末尾に半角大文字を追加 |
| 数字キー | 押した数字を全角 `０`〜`９` で未確定の文字列の末尾に加える |
| テンキー（数字: `VK_NUMPAD0`〜`VK_NUMPAD9` / `KP_0`〜`KP_9`、小数点: `VK_DECIMAL` / `KP_Decimal`、カンマ: `VK_SEPARATOR` / `KP_Separator`） | 数字は半角 `0`〜`9`、小数点は `．`、カンマは `，` を未確定の文字列の末尾に加える |
| 記号キー・句読点 | 記号表の文字を未確定の文字列の末尾に加える |
| `Backspace` | 末尾の1文字を削る |
| `Esc` | 未確定の文字列をすべて削除する |
| `Tab`・`Shift+Tab` | 何もしない |
| `Left`・`Right` | キャレットを左右に移動させる |

#### 変換済み

未確定の文字列を候補へ変換した状態。候補一覧は表示しない。

| キー | 動作 |
| --- | --- |
| `Space` | 対象文節の現在候補の次を選択し、候補一覧表示中へ移る。最後の候補の次は第一候補に戻る。候補が1つなら、その候補のまま一覧を開く。直前の変換が `Henkan` によるもののときは、その1文節の通常の第一候補を選択し、変換済みを維持する |
| `Enter` | 「全体の確定・編集」節に従って一括確定する |
| 非修飾のアルファベットキー/数字キー/テンキーの数字 | 全体を一括確定し、押したキーの入力を新たに始める |
| Shift+アルファベットキー | 「モード」節に従って半角英数入力モードへ切り替え、未確定文字列に半角大文字を追加する |
| 記号キー/句読点/テンキーの小数点・カンマ | 「全体の確定・編集」節に従って表示文字列に追加する |
| `Backspace` | 「全体の確定・編集」節に従って末尾1文字を削る |
| `Esc` | 「全体の確定・編集」節に従って全体を読みに戻す |
| `Tab`・`Shift+Tab` | 何もしない |
| `Left`・`Right` | 「文節選択」節に従って対象文節を移す |
| `Shift+Left`・`Shift+Right` | 「境界伸縮」節に従って対象文節の境界を動かす |

#### 候補一覧表示中

変換モードで候補一覧を表示している状態。

| キー | 動作 |
| --- | --- |
| `Space` | 入力を確定せず選択を次の候補へ移す。最後の候補の次は第一候補に戻る |
| `Tab` | 最初の `Tab` で、選択位置を保ったまま1ページ最大30件に展開する。展開後は何もしない |
| `Shift+Tab` | 展開中は、選択位置を保ったまま1ページ最大10件に折りたたむ。展開していないときは何もしない |
| `Up`・`Down` | 前・次の候補へ移す。展開前は表示中の最大10件で循環し、展開後はページをまたいで全候補を循環する |
| `PageUp`・`PageDown` | 前・次のページへ移す |
| `Left`・`Right` | 「文節選択」節に従って対象文節を移す。ページは送らない |
| `Shift+Left`・`Shift+Right` | 「境界伸縮」節に従って対象文節の境界を動かす |
| `Enter` | 「全体の確定・編集」節に従って一括確定する |
| `Backspace` | 「全体の確定・編集」節に従って末尾1文字を削る |
| `Esc` | 文節ごとの選択候補と対象文節を保ったまま、変換済みへ移る |
| 非修飾のアルファベットキー/数字キー/テンキーの数字 | 全体を一括確定し、押したキーの入力を新たに始める |
| Shift+アルファベットキー | 「モード」節に従って半角英数入力モードへ切り替え、未確定文字列に半角大文字を追加する |
| 記号キー/句読点/テンキーの小数点・カンマ | 「全体の確定・編集」節に従って表示文字列に追加する |

### 全体の確定・編集

変換済みと候補一覧表示中の `Enter` は、全文節の現在の表示文字列を順番に連結して一括確定し、未入力へ移る。候補がない文節の読みも含める。

両状態の `Backspace` は、全文節の現在の表示文字列を連結したものから末尾1文字を削る。文字列が残れば、その文字列を変換前の未確定文字列として編集し、なくなれば未入力へ移る。

変換済みの `Esc` は、全文節を連結した読みに戻し、変換前へ移る。かなはひらがなに戻し、混在する英数字・記号は保持する。

変換済みと候補一覧表示中の記号キー・句読点・テンキーの小数点とカンマは、全文節の現在の表示文字列を連結したものの末尾へ、対応する文字を追加する。入力全体を未確定のまま変換前へ移し、候補一覧を閉じて展開を解除する。文字の対応は「記号」「句読点」「未入力」の各節に従う。

### アプリ内の未確定表示

アプリが未確定文字列（preedit）の表示に対応し、アプリ内表示が有効なとき、Weasel と fcitx5-rime は次の文字列をアプリ内へ表示する。

| 日本語入力の状態 | アプリ内の未確定文字列 |
| --- | --- |
| 変換前 | 入力中の読み |
| 変換済み | 全文節の現在の表示文字列を順番に連結したもの |
| 候補一覧表示中 | 全文節の現在の表示文字列を順番に連結したもの。対象文節の候補を移動するたびに、その選択結果へ追従する |

候補ウィンドウ上部に表示する読みは、アプリ内の未確定文字列とは別の表示として扱う。

### 候補一覧の表示

候補一覧を開いた直後は最大10件を表示し、10件未満なら存在する候補のみを表示する。最初の `Tab` で展開した後は1ページ最大30件を表示し、30件を超える候補は `PageUp`、`PageDown` でページを前後に送り、表示中はマウスホイールでも送る。候補一覧のラベルは各ページの先頭から `1`〜`30` と連番にし、次のページでも `1` から振り直す。filter 後の最終表示順で各ページの先頭となる候補には `Page 1`、`Page 2`、… を補足表示し、その候補の既存の補足情報も残す。確定して次の読みを入力したとき、`Backspace` または `Esc` で読みに戻ったとき、および展開中の `Shift+Tab` で折りたたんだときは展開状態を解除し、次の候補一覧も最大10件から始める。`Control+y`、`Alt+v`、`Control+v`、`,`、`.`、`-`、`=` はページ送りに使わない。

### MS-IME との差

MS-IME の標準設定との差を次に示す。

- `Space`: MS-IME は候補一覧を表示していないとき、入力を確定せず候補一覧を表示し、第一候補を選択する。Rime は1回目の `Space` では候補一覧を表示せず第一候補へ変換し、2回目から候補一覧を表示する
- `Tab`: MS-IME は候補一覧ウィンドウを展開してすべてのページを表示し、展開後の `Tab` は選択を次の候補へ移す。Rime は1ページ最大30件に展開し、展開後の `Tab` は何もしない
- `Henkan`: MS-IME は通常の候補変換をする。Rime は確定せず第一候補をカタカナにして変換済みへ移る
- `F6`〜`F10`: MS-IME は文字種変換をする。Rime は対応しない

## 記号

日本語入力中の記号キーは、記号表の文字を未確定の文字列の末尾に加える。引用符は開きと閉じを一組として加える。ここにない ASCII 記号キーは対応する全角字形を加える。変換前に `-` を押したときは、`ー` を読みの末尾に加えて変換を続ける。

| キー | 文字 |
| --- | --- |
| `-` | `ー` |
| `/`、`\`、`~` | `・`、`￥`、`〜` |
| 縦線キー | `·` |
| `[`、`]`、`{`、`}` | `「`、`」`、`『`、`』` |
| `'`、`"` | `‘’`、`“”` |

## ローマ字表

ローマ字からかなへの対応の正本は `dotfiles/rime/roma.data.yaml` の宣言である。`dotfiles/rime/roma.build.ts` が build 時に宣言から `kagiroi_dotfiles_romaji.dict.yaml` を生成し、辞書そのものをリポジトリに置かない。宣言は MS-IME 用の宣言（`undotfiles/ime/roma-table.yaml`）から独立しており、両者の一致は保証しない。Kagiroi 標準の `kagiroi_romaji` 辞書は `import_tables` で取り込まず、`speller/algebra` の派生綴り（`ti` → `chi` など）も無効にする。宣言と Kagiroi 標準の綴り衝突は宣言側のかなで置き換わる（`wi` は `うぃ`、`tha` は `ちゃ`、`va` は `ヴぁ`、`lka` は `ヵ` など）。

入力中は宣言に一致する綴りをかなへ変換する。入力中の未変換英字列全体が宣言に一致しないときも、末尾に一致する綴りがあれば最長のものをかなへ変換し、その前の英字を原文のまま残す。末尾にも一致する綴りがなければ英字列をそのまま表示する。たとえば `fdsa` は `fdさ`、宣言にない `shi` は `sひ`、宣言にある `sha` は `しゃ` と表示される。

宣言は入力インフラとして、次の対応も持つ。

| 綴り | かな | 目的 |
| --- | --- | --- |
| 子音の重複（`kk` `tt` など） | 重複子音に対応する促音（`kkanji` は `っかんじ` と表示される） | 促音入力の音節 |
| `-` | `ー` | 長音の入力 |

撥音の音節（`nk` `nt` `nwa` `nwi` `nwe` `nwo` など）は保持しない。`n` に子音が続く入力の「ん」は n の過不足補完が置くため、`nka` は `んか`、`nwo` は `んを` と表示される。`q` は `q` のままかなに変換されない。

## 句読点

日本語入力モードでは、`,` と `.` を押すと、未確定の文字列の末尾に `、` と `。` を加える。候補一覧を表示せず、編集中の文字列を確定しない。変換済みと候補一覧表示中の追加位置と状態遷移は「全体の確定・編集」節に従う。テンキーの小数点 `KP_Decimal` は `。` ではなく `．` を加える。`ascii_punct`（半角句読点モード）はセッションの開始時に毎回無効になる。

## 配置

同じ Rime 設定を次のユーザーデータディレクトリへ配置する。

- Windows / Weasel: `%APPDATA%/Rime`
- Linux / fcitx5-rime: `~/.local/share/fcitx5/rime`

dotfiles は共通の `default.custom.yaml`、`kagiroi.custom.yaml`、`kagiroi_romaji.custom.yaml`、ローマ字表の宣言 `roma.data.yaml` と辞書生成スクリプト `roma.build.ts`、n の過不足補完と共通キー・候補操作の Lua、Weasel 固有の `weasel.custom.yaml`、Linux 固有の fcitx5 設定 `fcitx5/config` と `fcitx5/conf/rime.conf` を管理する。`fcitx5/conf/rime.conf` は、Linux の fcitx5-rime のアプリ内未確定表示を制御する設定として `~/.config/fcitx5/conf/rime.conf` へ配置する。Linux の fcitx5 では、`fcitx5/config` が `Muhenkan` を入力メソッドの無効化に割り当てる。fcitx5 が入力メソッドを無効化している間はキーが Rime に渡らず、fcitx5 の標準トリガーで戻る。Weasel の表示設定は Linux の fcitx5-rime の表示に影響しない。Kagiroi の標準ローマ字 processor とスキーマ構成を保ち、Rime が生成するデータベース、ユーザー辞書、学習データは既存内容を保持する。

## 開発と検証

変更はこの SPEC、対応する自動テスト、実装の順に同期する。ローマ字表の変更は `roma.data.yaml` の宣言に対して行い、辞書は `roma.build.ts` が build 時に生成する。完了判定は `just test-rime` の成功とし、Windows の Weasel と Linux の fcitx5-rime での実機確認を要しない。
