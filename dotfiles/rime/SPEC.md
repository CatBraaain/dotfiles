# Kagiroi 日本語入力

対象は、Windows の Weasel と Linux の fcitx5-rime から共通の Kagiroi 日本語変換を使う Rime ユーザー設定である。設定ファイルは dotfiles で管理し、Windows と Linux の各 Rime ユーザーデータディレクトリへ配置する。Kagiroi のスキーマ、辞書、Lua プラグインが利用可能な環境を前提とする。

## 変換

Rime の選択スキーマは Kagiroi とする。ローマ字からかなへの変換は Kagiroi 標準のローマ字 processor（Lua の kana speller と script_translator）の仕組みに従い、対応表は「ローマ字表」節のとおりとする。連続する `n` の入力には次節の過不足補完を挟む。編集中の読みは、漢字変換が確定する前のローマ字入力の結果として表示されるかなである。変換候補には、編集中の読みと一致する語と、読みから変換できる辞書語が含まれる。

| 編集中の読み | 変換候補に含まれる文字列 |
| --- | --- |
| `かんじ` | `かんじ`、`漢字`、`感じ` のいずれか |
| `かな` | `かな` |

選択して確定した変換候補はユーザー辞書に記録し、同じ読みの変換では選択した回数に応じて上位の候補として表示する。

## n の過不足補完

連続する `n` を含む入力は、次のように補正する。ペアの変換と不足の補完は入力中と変換時に行い、過剰の補正は変換時にのみ行う。

- ペア: `n` が2個連続したとき、2個目の `n` の打鍵で宣言の `nn` 綴りとして即座に「ん」にする(`nn` は「ん」と表示される)。ただし、その直後のキーが母音(`a` `i` `u` `e` `o` `y`)のときは、末尾の「ん」を「ん」+`n` に戻して母音と結合する(`kanna` は「かんな」、`nnyo` は「んにょ」と表示される)。すでに「ん」が2個並んで確定しているとき(`nnnn` 由来)は戻さない(`kannnna` は「かんんあ」)。
- 不足:「ん」になるべき `n` が1個のとき、`n` を「ん」として扱う。入力中は `n` の直後に子音が来たとき(`kanji` は `かんじ` と表示される)、変換時は末尾の `n` に対して(`kan` は `かん` で変換される)。`y` が続く場合は「ん」にせず、`nya` は `にゃ` と表示される。
- 過剰: 編集中の読みに「ん」が連続しているとき(日本語の語に「んん」という連続は存在しない)。変換時に連続する「ん」を1つに畳む。余った「ん」は、直後に母音(`a` `i` `u` `e` `o` `y`)が続くとき、次の音節の頭の `n` としてその母音と結合する。

| 入力 | 入力中の表示 | Space で変換するときの読み |
| --- | --- | --- |
| `nn` | `ん` | `ん` |
| `kan` | `かn` | `かん` |
| `kann` | `かん` | `かん` |
| `nna`、`nnyo` | `んな`、`んにょ` | `んな`、`んにょ` |
| `kanji` | `かんじ` | `かんじ` |
| `kanda`、`kannda` | `かんだ` | `かんだ` |
| `kana`、`nya` | `かな`、`にゃ` | `かな`、`にゃ` |
| `kanna`、`kannna` | `かんな` | `かんな` |
| `kannnna` | `かんんあ` | `かんな` |
| `konnnitiha` | `こんにちは` | `こんにちは` |
| `kannnji` | `かんんじ` | `かんじ` |
| `kannnen` | `かんねn` | `かんねん` |
| `kannnnen` | `かんんえn` | `かんねん` |
| `nwa`、`nwi`、`nwe`、`nwo` | `んわ`、`んうぃ`、`んうぇ`、`んを` | `んわ`、`んうぃ`、`んうぇ`、`んを` |

## Windows / Linux 共通の操作と候補表示

Windows の Weasel と Linux の fcitx5-rime で Kagiroi を使用するとき、`Zenkaku_Hankaku` は Rime の日本語入力と英字入力を切り替える。切り替えで未確定の文字列を確定しない。未確定の文字列は英字入力中も保持され、日本語入力へ戻るとそのまま再開できる。英字入力中の入力は、保持された未確定の文字列に影響しない。英字入力中は英数字・記号・空白を半角で入力する。Windows の Weasel では、入力状態の通知とトレイアイコンを表示しない。候補一覧の表示中、マウスホイールでページを前後に送る。

日本語入力中は、`Enter` による確定指示以外で、未確定の文字列を確定しない。数字キー・記号キー・句読点・半角英字は、未確定の文字列の末尾にそのまま加える。変換モードで押したときは、選択中の候補の文字列に続けて加える。未確定の文字列がないとき、または全角空白のみからなるときに `Space` を押すと、全角空白 `　` を加える。英字キーはローマ字からかなへの入力に使う。ただし未確定の文字列に数字・記号・句読点・半角英字を加えた後は、続くローマ字入力をかなに変換せず、そのまま加える。入力開始から候補一覧を表示しない。1回目の `Space` も候補一覧を表示せず第一候補へ変換し、候補一覧は2回目の `Space` から表示する。`Space` または `Henkan` で候補へ変換した未確定状態を変換モードと呼ぶ。確定して次の入力を始めると、再び候補一覧を表示しない。編集中の文字列があるときのキー操作は次のとおりである。MS-IME の挙動は標準設定を基準とし、数字キーだけは表中のオプションをオフにした場合と比較する。Rime 列の「同じ」は、対応する MS-IME 列の挙動を指す。

| キー | MS-IME の挙動 | Rime での設定 |
| --- | --- | --- |
| `Space` | 候補一覧を表示していないとき、入力を確定せず候補一覧を表示し、第一候補を選択する。表示しているとき、入力を確定せず選択を次の候補へ移す。最後の候補の次は第一候補に戻る | 未確定の文字列がないとき、または全角空白のみからなるとき、全角空白 `　` を加える。読みの入力中に押すと、入力を確定せず第一候補へ変換して候補一覧は非表示のままにする。続けて押すと候補一覧を表示して第二候補を選択する。以降は入力を確定せず選択を次の候補へ移し、最後の候補の次は第一候補に戻る。変換できる読みを持たない未確定の文字列（数字・記号・句読点・半角英字を含むもの）に対する `Space` は、その文字列をそのまま確定する |
| `Tab` | 候補一覧を表示しているとき、候補一覧ウィンドウを展開してすべてのページを表示する。展開後の `Tab` は選択を次の候補へ移す | 候補一覧を表示中の最初の `Tab` で、選択位置を保ったまま1ページ最大30件に展開する。展開後の `Tab` は何もしない。展開中の `Shift+Tab` は、選択位置を保ったまま1ページ最大10件に折りたたむ。展開していないときの `Shift+Tab`、および候補一覧が非表示のときの `Tab`・`Shift+Tab` は何もしない |
| `Up`・`Down` | この表では比較しない | 候補一覧を表示中は前・次の候補へ移す。展開前は表示中の最大10件で循環し、展開後はページをまたいで全候補を循環する |
| `PageUp`・`PageDown` | この表では比較しない | 候補一覧を表示中は前・次のページへ移す |
| `Enter` | 選択中の候補を確定する | 同じ |
| `Backspace` | 候補一覧の表示状態にかかわらず、編集中の文字列を末尾から1文字削る。変換モードでは選択中の候補の文字列から削って変換モードを終え、候補一覧を非表示にする。確定はしない | 同じ。1回目の `Space` または `Henkan` による候補一覧非表示の変換中も、表示中の変換文字列を末尾から1文字削る。さらに押すたびに残りの文字列を末尾から1文字ずつ削り、最後の1文字を削ると編集中の文字列はなくなる |
| `Esc` | 変換モードでは、確定せず元のひらがなの読みへ戻して候補一覧を非表示にする。変換モード以外では、残った全角未確定文字列をすべて削除する | 同じ。変換モード以外では、残った未確定文字列をすべて削除する |
| `Henkan` | 通常の候補変換をする | 確定せず第一候補をカタカナにして候補一覧を非表示にする。続く `Space` は候補一覧を表示して第一候補を選択する |
| 修飾キーなしの英字キー | 選択中の候補で確定し、押したキーを次の全角入力の読みにする | 読みの入力中は、押したキーをローマ字からかなへの入力に使う。変換モードでは、選択中の候補の文字列に押した英字をそのまま（かなに変換せず）加える |
| `Shift+A` など Shift と英字キー | この表では比較しない | 選択中の候補があればその文字列に、なければ未確定の文字列の末尾に、半角英字 `A` などを加える |
| 数字キー | 選択中の候補で確定し、押したキーを次の全角入力の読みにする（「メインキーボードの数字キーで候補を選択する」をオフにした場合） | 未確定の文字列の末尾に、押した数字を全角 `０`〜`９` で加える。読みの入力中も変換中も同じであり、候補番号の選択には使わない |
| テンキー | この表では比較しない | 数字キー（`KP_0` 〜 `KP_9`）は未確定の文字列の末尾に半角数字 `0`〜`9` を加える。`KP_Enter` は `Enter` と同じ動作をする。`KP_Decimal` は未確定の文字列の末尾に `．` を加える |
| その他の通常入力キー | この表では比較しない | 確定せず、記号表の文字を未確定の文字列の末尾に加える |
| F6〜F10 | 文字種変換をする | 対応しない |

候補一覧を開いた直後は最大10件を表示し、10件未満なら存在する候補のみを表示する。最初の `Tab` で展開した後は1ページ最大30件を表示し、30件を超える候補は `PageUp`、`PageDown` またはマウスホイールでページを前後に送る。候補一覧のラベルは各ページの先頭から `1`〜`30` と連番にし、次のページでも `1` から振り直す。filter 後の最終表示順で各ページの先頭となる候補には `Page 1`、`Page 2`、… を補足表示し、その候補の既存の補足情報も残す。確定して次の読みを入力したとき、`Backspace` または `Esc` で読みに戻ったとき、および展開中の `Shift+Tab` で折りたたんだときは展開状態を解除し、次の候補一覧も最大10件から始める。`Control+y`、`Alt+v`、`Control+v`、`,`、`.`、`-`、`=` はページ送りに使わない。

## 記号

日本語入力中の記号キーは、記号表の文字を未確定の文字列の末尾に加える。引用符は開きと閉じを一組として加える。ここにない ASCII 記号キーは対応する全角字形を加える。読みの入力中に `-` を押したときは、`ー` を読みの末尾に加えて変換を続ける。

| キー | 文字 |
| --- | --- |
| `-` | `ー` |
| `/`、`\`、`~` | `・`、`￥`、`〜` |
| 縦線キー | `·` |
| `[`、`]`、`{`、`}` | `「`、`」`、`『`、`』` |
| `'`、`"` | `‘’`、`“”` |

## ローマ字表

ローマ字からかなへの対応の正本は `dotfiles/rime/roma.data.yaml` の宣言である。`dotfiles/rime/roma.build.ts` が build 時に宣言から `kagiroi_dotfiles_romaji.dict.yaml` を生成し、辞書そのものをリポジトリに置かない。宣言は MS-IME 用の宣言（`undotfiles/ime/roma-table.yaml`）から独立しており、両者の一致は保証しない。Kagiroi 標準の `kagiroi_romaji` 辞書は `import_tables` で取り込まず、`speller/algebra` の派生綴り（`ti` → `chi` など）も無効にする。宣言と Kagiroi 標準の綴り衝突は宣言側のかなで置き換わる（`wi` は `うぃ`、`tha` は `ちゃ`、`va` は `ヴぁ`、`lka` は `ヵ` など）。

入力中は宣言に一致する綴りをかなへ変換する。入力中の未変換英字列全体が宣言に一致しないときも、末尾に一致する綴りがあれば最長のものをかなへ変換し、その前の英字を原文のまま残す。末尾にも一致する綴りがなければ英字列をそのまま表示する。たとえば `fdsa` は `fdさ`、宣言にない `shi` は `sひ`、宣言にある `sha` は `しゃ` と表示される。

宣言は入力インフラとして、次の対応も持つ。

| 綴り | かな | 目的 |
| --- | --- | --- |
| 子音の重複（`kk` `tt` など） | 重複子音に対応する促音（`kkanji` は `っかんじ` と表示される） | 促音入力の音節 |
| `-` | `ー` | 長音の入力 |

撥音の音節（`nk` `nt` `nwa` `nwi` `nwe` `nwo` など）は保持しない。`n` に子音が続く入力の「ん」は n の過不足補完が置くため、`nka` は `んか`、`nwo` は `んを` と表示される。`q` は `q` のままかなに変換されない。

## 句読点

日本語入力モードでは、`,` と `.` を押すと、未確定の文字列の末尾に `、` と `。` を加える。候補一覧を表示せず、編集中の文字列を確定しない。変換候補の選択中に押したときは、選択中の候補の文字列に続けて加える。テンキーの小数点 `KP_Decimal` は `。` ではなく `．` を加える。`ascii_punct`（半角句読点モード）はセッションの開始時に毎回無効になる。

## 配置

同じ Rime 設定を次のユーザーデータディレクトリへ配置する。

- Windows / Weasel: `%APPDATA%/Rime`
- Linux / fcitx5-rime: `~/.local/share/fcitx5/rime`

dotfiles は共通の `default.custom.yaml`、`kagiroi.custom.yaml`、`kagiroi_romaji.custom.yaml`、ローマ字表の宣言 `roma.data.yaml` と辞書生成スクリプト `roma.build.ts`、n の過不足補完と共通キー・候補操作の Lua、Weasel 固有の `weasel.custom.yaml` を管理する。Weasel の表示設定は Linux の fcitx5-rime の表示に影響しない。Kagiroi の標準ローマ字 processor とスキーマ構成を保ち、Rime が生成するデータベース、ユーザー辞書、学習データは既存内容を保持する。

## 開発と検証

変更はこの SPEC、対応する自動テスト、実装の順に同期する。ローマ字表の変更は `roma.data.yaml` の宣言に対して行い、辞書は `roma.build.ts` が build 時に生成する。完了判定は `just test-rime` の成功とし、Windows の Weasel と Linux の fcitx5-rime での実機確認を要しない。
