# Kagiroi 日本語入力

Windows の Weasel と Linux の fcitx5-rime で共通に使う Rime ユーザー設定の仕様である。Kagiroi のスキーマ・辞書・Lua プラグインが利用可能な環境を前提とし、利用者と実装・検証担当者が「今の状態でキーを押した結果」を読むために定める。設定ファイルは dotfiles で管理する。

- 日本語入力と半角英数入力は IME ON。半角英数入力も未確定文字列を編集する。IME OFF は半角文字をアプリへ直接入力し、未確定文字列を作らない。
- 読みはローマ字入力から得たかな等の文字列、文節は変換対象となる連続した読みの区間。`|` は文節境界、対象文節は今操作している文節を表す。
- OFF 予約は、未確定文字列を削除し終えるまで IME OFF への移行を保留する状態。解除・保持の条件は「半角切替と OFF 予約」に従う。

## 共通前提

操作表は Rime に到達するキーイベントを対象とする。Linux frontend が物理無変換を処理する境界は「配置」に従う。表示は、アプリ内の未確定文字列（preedit）の表示に対応し、アプリ内表示が有効な環境で読む。

- `Enter` は、現在表示している未確定文字列全体を表示どおりに一括確定する。変換中は全文節の表示を順に連結し、辞書候補がない文節の読みも含める。入力中に済んだ n のペア消費・不足補完は含むが、確定時に末尾 n 補完・過剰補正はしない。テンキーの Enter（Windows の拡張 `VK_RETURN` / Linux の `KP_Enter`）も同じ。
- 左 Shift 単独の押下・解放は、モード・OFF 予約・未確定文字列・候補一覧の開閉・展開・選択を保持する。
- キー列は左から順に押す。`ka` は `k → a` の2打鍵、`Shift+A` は修飾付きの1打鍵。文字追加・削除の例はキャレット末尾を前提とする。`␠` は半角空白1個、`　` は全角空白1個。
- 例に示す候補順・第一候補はその例の前提であり、辞書・学習に対して常に同じ順位を要求するものではない。

## 日本語入力：未入力

未確定文字列がない状態。

| キー | 動作 |
| --- | --- |
| `Space` | 全角空白 `　` を即確定で入力し、未入力のまま |
| 非修飾のアルファベットキー | ローマ字入力を始め、変換前へ。例: `k` は `k`、`ka` は `か` |
| 数字・テンキー・記号・句読点 | 「共通の文字対応」の文字を新たな未確定文字列に加え、変換前へ |
| Shift+アルファベットキー | 半角大文字の入力を始め、予約なしの半角英数入力へ。例: `Shift+A` は `A` |
| `Muhenkan` / `Zenkaku_Hankaku` | IME OFF へ |

## 日本語入力：変換前

候補への変換前の未確定文字列がある状態。アプリ内には入力中の読みを表示する。文字入力は「ローマ字表」「n の過不足補完」「共通の文字対応」に従う。

| キー | 動作 |
| --- | --- |
| アルファベットキー | 続くローマ字をかなへ変換して追加し、変換前のまま。例: `か１k` / `か1k` に `i` を入力すると `か１き` / `か1き` |
| 数字・テンキー・記号・句読点 | 「共通の文字対応」の文字を末尾に追加し、変換前のまま |
| `Space` | n の過不足補完後、全読みを自動分割した全文節の第一候補を連結して表示し、変換済みへ。対象は先頭文節、一覧は閉じたまま。例: 通常候補順 `蚊 / か` の読み `か` は `蚊` |
| `Henkan` | 読み全体を1文節としたカタカナ第一候補を表示し、変換済みへ。例: 読み `か` は `カ` |
| `Enter` | 全体を確定し、予約を解除して日本語入力の未入力へ |
| `Backspace` | 末尾1文字を削る。文字が残れば変換前のまま。全消去後は予約ありなら IME OFF、予約なしなら日本語入力の未入力へ |
| `Esc` | 全消去する。終了モードは `Backspace` と同じ |
| Shift+アルファベットキー | 表示・未完成ローマ字を保ち、半角大文字を末尾に追加して半角英数入力へ。予約は解除する |
| `Muhenkan` / `Zenkaku_Hankaku` | 表示・未完成ローマ字を保ち、半角英数入力へ切り替えて OFF 予約を作る |
| `Tab` / `Shift+Tab` | 何もしない。予約も保持する |
| `Left` / `Right` | 文字列を保ってキャレットを左右へ移動し、予約も保持する |

## 日本語入力：変換済み

未確定文字列を候補へ変換した状態。候補一覧は表示せず、アプリ内には全文節の現在の表示文字列を順に連結したものを表示する。候補操作は対象文節だけに作用する。

| キー | 動作 |
| --- | --- |
| `Space` | 次の候補を選び、候補一覧を開く。最後の次は第一候補、唯一候補ならそのまま一覧を開く。ただし直前が `Henkan` なら、その1文節の通常第一候補へ戻して変換済みを維持し、さらに次の `Space` で一覧を開く |
| `Enter` | 全体を確定し、予約を解除して日本語入力の未入力へ |
| 非修飾のアルファベットキー・数字キー・テンキーの数字 | 全体を一括確定し、押したキーで次の入力を始める。例: `今日` に `k` / `1` / `KP_1` なら、`今日` を確定して `k` / `１` / `1` を表示し、変換前へ |
| Shift+アルファベットキー | 変換表示を保ち、半角大文字を末尾に追加して半角英数入力へ。例: `今日` に `Shift+A` は `今日A`。予約は解除する |
| 記号・句読点・テンキーの小数点・カンマ | 全文節の表示を連結した末尾へ対応文字を追加し、全体を未確定のまま変換前へ。例: `今日` に `/` / `.` は `今日・` / `今日。` |
| `Backspace` | 全文節の表示を連結した末尾1文字を削り、残れば変換前、空なら日本語入力の未入力へ。例: `今日` は `今` |
| `Esc` | 全文節を連結した読みに戻して変換前へ。かなはひらがな、混在する英数字・記号は保持する。例: `今日\|Ab1・` は `きょうAb1・` |
| `Tab` / `Shift+Tab` | 何もしない |
| `Left` / `Right` | 前・次の文節へ対象を移す。先頭の `Left`・末尾の `Right` は動かない。各文節の候補を保持する |
| `Shift+Left` / `Shift+Right` | 対象文節の末尾境界を読みの1文字分縮める / 伸ばす。「文節と境界変更」の細則に従う |
| `Muhenkan` / `Zenkaku_Hankaku` | 変換表示を保ち、半角英数入力へ切り替えて OFF 予約を作る |

例えば通常候補順 `蚊 / か` の読み `か` に `Space → Space` を押すと、`蚊` への変換後に `か` を選んだ一覧が開く。唯一候補なら、その候補の一覧が開く。`Henkan → Space` では `カ` から `蚊` に戻り、一覧はまだ開かない。

## 日本語入力：候補一覧表示中

変換モードで対象文節の候補一覧が開いている状態。アプリ内には全文節の現在の表示を順に連結し、対象文節の選択変更に追従する。非展開は最大10件/ページ、展開は最大30件/ページ。「候補一覧の見た目」にラベル等を定める。

| キー | 動作 |
| --- | --- |
| `Space` | 確定せず、対象文節の次の候補を選ぶ。ページをまたいで全候補を循環し、最後の次は第一候補 |
| `Tab` | 選択位置を保って最大30件/ページに展開する。展開後は何もしない |
| `Shift+Tab` | 展開中なら選択位置を保って最大10件/ページに折りたたむ。非展開なら何もしない |
| `Up` / `Down` | 前・次の候補へ。非展開は表示中の最大10件で循環、展開はページをまたいで全候補を循環する |
| `PageUp` / `PageDown` | 前・次のページの先頭候補を選ぶ。先頭の前は最終、最終の次は先頭へ循環する。1ページだけでもその先頭を選ぶ |
| マウスホイール | ページを送る |
| `Left` / `Right` | 前・次の文節へ対象と一覧を切り替え、全文節の選択候補・一覧の表示状態を保持する。先頭・末尾では動かず、ページは送らない |
| `Shift+Left` / `Shift+Right` | 対象文節の末尾境界を読みの1文字分縮める / 伸ばす。「文節と境界変更」の細則に従い、一覧の開閉・展開は保持する |
| `Enter` | 全体を確定し、予約を解除して日本語入力の未入力へ。一覧を閉じて展開を解除する |
| `Backspace` | 全文節の表示を連結した末尾1文字を削る。残れば変換前、空なら日本語入力の未入力へ。一覧を閉じて展開を解除する。例: `今日` は `今`、`京` は空になる |
| `Esc` | 文節ごとの選択候補と対象文節を保って変換済みへ。一覧を閉じる |
| 非修飾のアルファベットキー・数字キー・テンキーの数字 | 全体を一括確定し、押したキーで次の入力を始めて変換前へ。一覧を閉じて展開を解除する |
| Shift+アルファベットキー | 表示を保ち、半角大文字を末尾に追加して半角英数入力へ。予約を解除し、一覧を閉じて展開を解除する |
| 記号・句読点・テンキーの小数点・カンマ | 全文節の表示を連結した末尾へ対応文字を追加し、全体を未確定のまま変換前へ。一覧を閉じて展開を解除する |
| `Muhenkan` / `Zenkaku_Hankaku` | 表示と一覧の開閉・展開・選択を保ち、半角英数入力へ切り替えて OFF 予約を作る |
| `Control+y` / `Alt+v` / `Control+v` | ページ送りには使わない |

`,`・`.`・`-`・`=` もページ送りではなく文字追加である。選択候補 `京` に `-` / `,` / `KP_Decimal` / `KP_Separator` を加える例では、`京ー` / `京、` / `京．` / `京，` となる。

読み `きょう`、候補順 `今日 / 京 / 凶` で `京` を選んでいる例では、`Esc` で `京` のまま変換済み、次の `Esc` で `きょう` の変換前、さらに `Esc` で全消去して未入力となる。

## 半角英数入力

IME ON のまま半角文字を未確定文字列へ追加・編集する状態。OFF 予約の有無と、切替前から保持した一覧の有無を区別する。切替で保持する内容は「半角切替と OFF 予約」に従う。

| キー | 動作 |
| --- | --- |
| アルファベット・数字・テンキー・記号・句読点 | 半角文字を末尾に追加する。Shift+英字は半角大文字。予約を解除し、一覧を閉じて展開を解除する |
| `Space` | 半角空白 `␠` を末尾に追加する。予約を解除し、一覧を閉じて展開を解除する |
| `Zenkaku_Hankaku` | 未確定文字列と予約を保持して日本語入力の変換前へ戻る。既存の表示は再解釈しない |
| `Muhenkan` | 未確定文字列があれば保持して OFF 予約を作る。すでに予約中でも保持する。なければ IME OFF へ |
| `Enter` | 全体を確定し、予約を解除して日本語入力の未入力へ |
| `Backspace` | 末尾1文字を削る。残れば半角英数入力と予約の有無を保持する。空なら予約ありは IME OFF、予約なしは日本語入力の未入力へ |
| `Esc` | 全消去する。終了モードは `Backspace` と同じ |
| 保持した一覧で候補を選ぶキー（例: `Up` / `Down`） | 既存の候補一覧操作に従って選択し、予約を解除して日本語入力を続ける。一覧の展開状態も保持する |

例えば `Ab1` から日本語入力へ戻って `ki` を入力すると `Ab1き`、テンキーの `KP_1 → KP_Decimal → KP_Separator` を半角入力で `A` に加えると `A1.,` となる。

予約ありの `か` から日本語入力へ戻ると変換前予約となる。そこで `Tab` は予約を保ち、続く `Backspace` による全消去で IME OFF になる。一方、`Space` は予約を解除して通常の変換を行うため、その後 `Esc → Esc` で全消去すると日本語入力の未入力になる。

## IME OFF

未確定文字列を作らない状態。

| キー | 動作 |
| --- | --- |
| 非修飾の `Zenkaku_Hankaku` press | 日本語入力の未入力へ。続く `ka` は `か` の変換前となる |
| `Zenkaku_Hankaku` release / 修飾付き `Zenkaku_Hankaku`（例: `Control+Zenkaku_Hankaku`） | モードを切り替えない |
| その他（`Muhenkan` を含む） | 半角文字をアプリへ直接入力するか、通常の frontend 動作に従う。例: `a` は直接入力する |

## 共通の文字対応

日本語入力で加える文字を定める。追加位置と状態遷移は各状態の操作表に従う。テンキー名は Windows / Linux の順で併記し、`KP_*` は Windows の Rime 内部でも使う共通キー名である。`ascii_punct`（半角句読点モード）はセッション開始時に毎回無効になる。

| キー | 動作 |
| --- | --- |
| 数字キー | 全角 `０`〜`９` を加える |
| テンキーの数字（`VK_NUMPAD0`〜`VK_NUMPAD9` / `KP_0`〜`KP_9`） | 半角 `0`〜`9` を加える |
| テンキーの小数点（`VK_DECIMAL` / `KP_Decimal`） | `．` を加える |
| テンキーのカンマ（`VK_SEPARATOR` / `KP_Separator`） | `，` を加える |
| `,` / `.` | `、` / `。` を加える |
| `-` | `ー` を加える |
| `/` / `\` / `~` | `・` / `￥` / `〜` を加える |
| 縦線キー | `·` を加える |
| `[` / `]` / `{` / `}` | `「` / `」` / `『` / `』` を加える |
| `'` / `"` | 引用符のペア `‘’` / `“”` を加える |
| 上記以外の ASCII 記号 | 対応する全角字形を加える |

## n の過不足補完

入力中と変換時にはペア消費・不足補完を行い、過剰補正は変換時だけ行う。「文字入力」の表が表示と `Space` 時の読みの例である。

- ペア消費: 2個目の `n` の打鍵で `nn` を「ん」にする。消費した `n` は、後続の母音や `y` に補わない。
- 不足補完: 入力中は直後に子音が来た `n`、変換時は末尾の `n` を「ん」にする。`y` が続く場合は「ん」にしない。
- 過剰補正: 日本語の語に「んん」という連続は存在しないため、変換時に連続する「ん」を1つに畳む。余った「ん」は、直後の `a`・`i`・`u`・`e`・`o`・`y` と次の音節を作る頭の `n` として結合する。

## 半角切替と OFF 予約

半角入力への切替では、変換表示・未完成ローマ字・候補一覧の開閉・展開・選択を保持する。日本語入力へ戻ると、保持した表示・未完成ローマ字・半角入力中の追加文字を再解釈せず変換前の編集対象とし、続くローマ字だけをかなへ変換する。

OFF 予約は文字追加・確定・変換・候補選択で解除し、削除・キャレット移動・左 Shift 単独・実際に何も起こさないキーでは保持する。文字追加は一覧を閉じて展開も解除する。全消去後のモードは入り方の履歴ではなく予約の有無で決まる。

例えば `かn` から `Muhenkan → Enter` で確定する表示は `かn`。`Shift+A → Zenkaku_Hankaku → ki` なら `かnAき` となる。未完成の `k` から `Muhenkan → a → Zenkaku_Hankaku → ki` なら `kaき`、変換表示 `今日` から `Muhenkan → b → Zenkaku_Hankaku → ki` なら `今日bき` となる。

展開した一覧で `京` を選んだまま `Muhenkan` を押す例では、半角英数入力に予約と一覧を保持する。続く `Down` は `凶` を選んで日本語入力の一覧へ戻り、展開も保持する。非展開の同じ候補順で `Up` なら `今日` を選び、非展開を保持する。`Space` を押す場合は候補選択でなく半角空白追加となり、`京␠` の半角英数入力へ移って予約・一覧・展開を解除する。

## 文節と境界変更

全読みを辞書と連接評価で自動分割し、辞書候補がない文節は読みを唯一の候補とする。読み `きょうはかれー` は `きょうは|かれー` に分割する。各第一候補が `今日は / カレー` なら表示は `今日はカレー`、`Esc` で読みに戻すと `きょうはかれー` となる。他の読みの境界は辞書・連接評価・学習に応じて決まり、境界伸縮で調整できる。1文節になる条件で辞書候補のない `q` は、変換後も唯一候補 `q` を表示する。

文節移動は全文節を未確定のまま保ち、各文節の選択候補と一覧の表示状態を保持する。一覧には対象文節の候補だけを表示し、候補操作は対象文節だけに作用する。例えば文節1の候補順が `今日は / 京は`、文節2が `カレー / かれー` の各第一候補から、`Right → Down` で対象を文節2へ移して選ぶと `今日はかれー` になる。文節1はそのまま、一番左・右の文節を越えて移動しない。

境界を動かす単位は読みの Unicode コードポイント1個。小書きかな・長音符・英字・数字・記号も各1文字として数える。

- 縮める場合: 対象の読みが2文字以上なら末尾1文字を次文節の先頭へ移す。最後の文節なら、その文字を切り出して新しい次文節を作る。読みが1文字なら境界を保つ。
- 伸ばす場合: 次文節の先頭1文字を対象の末尾へ取り込み、空になった次文節は除く。最後の文節なら境界を保つ。
- 境界が動いた場合: 読みが変わった両側を第一候補へ再変換する。対象文節は同じ文節を保ち、読みが変わらない文節の境界・選択候補を保持する。一覧の開閉・展開も保持し、開いていれば対象の新しい第一候補を選んで表示する。

例として、読み `あい|う|え`、選択 `愛|宇|絵` の文節1を縮めると `あ|いう|え`、伸ばすと `あいう|え` になる。新しい読み `あ`・`いう`・`あいう` に辞書候補がなければ表示は `あいう絵` で、文節3の `絵` は保持する。展開した一覧で縮めた場合も展開を保ち、対象の一覧は唯一候補 `あ` となる。

最後の1文節 `あい` を縮めると `あ|い`、`きゃ` を縮めると `き|ゃ` になる。各新しい読みに辞書候補がなければ各読みを表示する。読み1文字の `う|え` を縮めても `宇|絵` は変わらず、最後の文節 `あい` を伸ばしても選択 `愛` は変わらない。

## 候補一覧の見た目

一覧は既定で閉じ、入力開始・確定後の次入力では閉じる。新たな一覧は非展開の最大10件から始まり、上限未満なら存在する候補だけを表示する。確定後の次の読み入力、`Backspace` または `Esc` で読みに戻ったときは展開を解除し、次の一覧も最大10件から始める。

ラベルは各ページの先頭から `1`〜`30` の連番にし、ページごとに `1` へ戻す。filter 後の最終表示順で各ページの先頭候補に `Page 1`、`Page 2`、… を補足表示し、既存の補足情報も残す。候補ウィンドウ上部の読みは、アプリ内 preedit とは別の表示である。

例えば読み `こう` の候補順が `公 / 工 / 口 / 江 / 幸 / 向 / 后 / 好 / 考 / 行 / 孝 / 抗 / 攻 / 更 / 効 / 肯 / 侯 / 厚 / 洪 / 皇 / 紅 / 郊 / 香 / 校 / 航 / 貢 / 高 / 康 / 控 / 黄 / 港` の31件で、`公` の既存補足が `共通` の場合、展開すると Page 1 は `公`〜`黄` の30件、Page 2 は `港` の1件になる。各ページのラベルは `1`〜`30` と `1`、先頭の補足は `Page 1` と `共通`、`Page 2` となる。

この例で非展開の先頭10件なら、`Up` は `公` から `行`、`Down` は `行` から `公` に循環する。展開中なら `公` の前は `港`、`行` の次は `孝`、`黄` の次は `港`、`港` の次は `公`。ページ移動は選択中の `工` を保つのでなく移動先の先頭を選び、Page 1 から前・次どちらへ送っても `港`、Page 2 から Page 1 へ送ると `公` になる。

## 変換候補と学習

Rime の選択スキーマは Kagiroi とする。ローマ字入力は Kagiroi 標準のローマ字 processor（Lua の kana speller と script_translator）の仕組みに従い、「ローマ字表」の対応と n の過不足補完を使う。

変換候補には入力中の読みと一致する語と、読みから変換できる辞書語を含める。例えば `かんじ` には `かんじ`・`漢字`・`感じ` のいずれか、`かな` には `かな` を含める。数字・記号・句読点・半角アルファベットも変換対象とし、英数字の基本候補には元の表記、全角・半角、大文字・小文字を含める。かなと英数字が混在する文字列の区切りや変換対象は、既存の変換処理に従う。

選択して確定した候補はユーザー辞書に記録し、同じ読みでは選択した回数に応じて上位に表示する。

## ローマ字表

ローマ字からかなへの対応の正本は `dotfiles/rime/roma.data.yaml` の宣言である。`dotfiles/rime/roma.build.ts` が build 時に宣言から `kagiroi_dotfiles_romaji.dict.yaml` を生成し、辞書そのものをリポジトリに置かない。宣言は MS-IME 用の宣言（`undotfiles/ime/roma-table.yaml`）から独立しており、両者の一致は保証しない。Kagiroi 標準の `kagiroi_romaji` 辞書は `import_tables` で取り込まず、`speller/algebra` の派生綴り（`ti` → `chi` など）も無効にする。宣言と Kagiroi 標準の綴り衝突は宣言側のかなで置き換わる（`wi` は `うぃ`、`tha` は `ちゃ`、`va` は `ヴぁ`、`lka` は `ヵ` など）。

入力中は宣言に一致する綴りをかなへ変換する。入力中の未変換英字列全体が宣言に一致しないときも、末尾に一致する綴りがあれば最長のものをかなへ変換し、その前の英字を原文のまま残す。末尾にも一致する綴りがなければ英字列をそのまま表示する。たとえば `fdsa` は `fdさ`、宣言にない `shi` は `sひ`、宣言にある `sha` は `しゃ` と表示される。

入力インフラとして、宣言は重複子音（`kk`・`tt` 等）に対応する促音の音節（`kkanji` は `っかんじ`）と、長音の `-` → `ー` も持つ。撥音の音節（`nk`・`nt`・`nwa`・`nwi`・`nwe`・`nwo` 等）は保持しない。子音前の「ん」は n 補完が置くため、`nka` は `んか`、`nwo` は `んを` と表示される。`q` はかなに変換せず `q` のまま表示する。

## MS-IME との比較

比較のために MS-IME の標準設定を示す。Rime は `F6`〜`F10` の文字種変換に対応しない。

| キー | 動作 |
| --- | --- |
| `Space` | MS-IME は一覧未表示のとき、確定せず一覧を表示して第一候補を選ぶ |
| `Tab` | MS-IME は一覧を展開してすべてのページを表示し、展開後は次候補へ移す |
| `Henkan` | MS-IME は通常の候補変換を行う |
| `F6`〜`F10` | MS-IME は文字種変換を行う |

## 配置

同じ Rime 設定を次のユーザーデータディレクトリへ配置する。

- Windows / Weasel: `%APPDATA%/Rime`
- Linux / fcitx5-rime: `~/.local/share/fcitx5/rime`

dotfiles は共通の `default.custom.yaml`、`kagiroi.custom.yaml`、`kagiroi_romaji.custom.yaml`、ローマ字表の宣言 `roma.data.yaml` と辞書生成スクリプト `roma.build.ts`、n の過不足補完と共通キー・候補操作の Lua、Weasel 固有の `weasel.custom.yaml`、Linux 固有の fcitx5 設定 `fcitx5/config` と `fcitx5/conf/rime.conf` を管理する。`fcitx5/conf/rime.conf` は、Linux の fcitx5-rime のアプリ内未確定表示を制御する設定として `~/.config/fcitx5/conf/rime.conf` へ配置する。Linux の fcitx5 では、`fcitx5/config` が `Muhenkan` を入力メソッドの無効化に割り当てる。fcitx5 が入力メソッドを無効化している間はキーが Rime に渡らず、fcitx5 の標準トリガーで戻る。Weasel の表示設定は Linux の fcitx5-rime の表示に影響しない。Kagiroi の標準ローマ字 processor とスキーマ構成を保ち、Rime が生成するデータベース、ユーザー辞書、学習データは既存内容を保持する。

Windows の Weasel では入力状態の通知とトレイアイコンを表示しない。

## 開発と検証

変更はこの SPEC、対応する自動テスト、実装の順に同期する。ローマ字表の変更は `roma.data.yaml` の宣言に対して行い、辞書は `roma.build.ts` が build 時に生成する。完了判定は `just test-rime` の成功とし、Windows の Weasel と Linux の fcitx5-rime での実機確認を要しない。
