# Kagiroi 日本語入力

対象は、Windows の Weasel と Linux の fcitx5-rime から共通の Kagiroi 日本語変換を使う Rime ユーザー設定である。設定ファイルは dotfiles で管理し、Windows と Linux の各 Rime ユーザーデータディレクトリへ配置する。Kagiroi のスキーマ、辞書、Lua プラグインが利用可能な環境を前提とする。

## 変換

Rime の選択スキーマは Kagiroi とする。ローマ字からかなへの変換は Kagiroi 標準のローマ字 processor に従い、連続する `n` の入力には次節の過不足補完を挟む。編集中の読みは、漢字変換が確定する前のローマ字入力の結果として表示されるかなである。変換候補には、編集中の読みと一致する語と、読みから変換できる辞書語が含まれる。

| 編集中の読み | 変換候補に含まれる文字列 |
| --- | --- |
| `かんじ` | `かんじ`、`漢字`、`感じ` のいずれか |
| `かな` | `かな` |

## n の過不足補完

連続する `n` を含む入力は、次のように補正する。不足の補完は入力中と変換時に行い、過剰の補正は変換時にのみ行う。

- 不足:「ん」になるべき `n` が1個のとき、`n` を「ん」として扱う。入力中は `n` の直後に子音が来たとき(`kanji` は `かんじ` と表示される)、変換時は末尾の `n` に対して(`kan` は `かん` で変換される)。
- 過剰: 編集中の読みに「ん」が連続しているとき(日本語の語に「んん」という連続は存在しない)。変換時に連続する「ん」を1つに畳む。余った「ん」は、直後に母音(`a` `i` `u` `e` `o` `y`)が続くとき、次の音節の頭の `n` としてその母音と結合する。

| 入力 | 入力中の表示 | Space で変換するときの読み |
| --- | --- | --- |
| `kan` | `かn` | `かん` |
| `kanji` | `かんじ` | `かんじ` |
| `kanda`、`kannda` | `かんだ` | `かんだ` |
| `kana`、`nya` | `かな`、`にゃ` | `かな`、`にゃ` |
| `kanna`、`kannna` | `かんな` | `かんな` |
| `kannnna` | `かんんあ` | `かんな` |
| `konnnitiha` | `こんにちは` | `こんにちは` |
| `kannnji` | `かんんじ` | `かんじ` |
| `kannnen` | `かんねn` | `かんねん` |
| `kannnnen` | `かんんえn` | `かんねん` |

## Windows / Linux 共通の操作と候補表示

Windows の Weasel と Linux の fcitx5-rime で Kagiroi を使用するとき、`Zenkaku_Hankaku` は Rime の日本語入力と英字入力を切り替える。Windows の Weasel では、入力状態の通知とトレイアイコンを表示しない。

日本語入力中は、入力開始から候補一覧を表示しない。次の入力では再び `Space` を押すまで候補一覧を表示しない。編集中の文字列があるときのキー操作は次のとおりである。MS-IME の挙動は標準設定を基準とし、数字キーだけは表中のオプションをオフにした場合と比較する。Rime 列の「同じ」は、対応する MS-IME 列の挙動を指す。

| キー | MS-IME の挙動 | Rime での設定 |
| --- | --- | --- |
| `Space` | 候補一覧を表示していないとき、入力を確定せず候補一覧を表示し、第一候補を選択する。表示しているとき、入力を確定せず選択を次の候補へ移す。最後の候補の次は第一候補に戻る | 同じ |
| `Enter` | 選択中の候補を確定する | 同じ |
| `Backspace` | ひらがなの読みを入力中で候補一覧が非表示のときは、前字を削除する。候補一覧を表示中または `Henkan` 後は、確定せずひらがなの読みへ戻して候補一覧を非表示にする | 同じ |
| `Esc` | 確定せず、編集中の文字列をひらがなの読みへ戻し、候補一覧を非表示にする | 同じ |
| `Henkan` | 通常の候補変換をする | 確定せず第一候補をカタカナにして候補一覧を非表示にする |
| 英字キー | 選択中の候補で確定し、押したキーを次の全角入力の読みにする | 同じ |
| 数字キー | 選択中の候補で確定し、押したキーを次の全角入力の読みにする（「メインキーボードの数字キーで候補を選択する」をオフにした場合） | 同じ |
| その他の通常入力キー | この表では比較しない | 選択中の候補で確定し、押したキーを次の全角入力の読みにする |
| F6〜F10 | 文字種変換をする | 対応しない |

## 配置

同じ Rime 設定を次のユーザーデータディレクトリへ配置する。

- Windows / Weasel: `%APPDATA%/Rime`
- Linux / fcitx5-rime: `~/.local/share/fcitx5/rime`

dotfiles は共通の `default.custom.yaml`、`kagiroi.custom.yaml`、n の過不足補完と共通キー・候補操作の Lua、Weasel 固有の `weasel.custom.yaml` を管理する。Weasel の表示設定は Linux の fcitx5-rime の表示に影響しない。Kagiroi の標準ローマ字 processor とスキーマ構成を保ち、Rime が生成するデータベース、ユーザー辞書、学習データは既存内容を保持する。

## 開発と検証

変更はこの SPEC、対応する自動テスト、実装の順に同期する。完了判定は `just test-rime` の成功とし、Windows の Weasel と Linux の fcitx5-rime での実機確認を要しない。
