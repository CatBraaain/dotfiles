# ローマ字定義コンパイラ

対象は、TypeScriptで宣言したローマ字表をMS-IME用のバイナリ値へコンパイルし、明示操作で適用する機能である。宣言は、空の状態から完全なマッピング集合を構成する。既存の表やOS設定を入力にする差分適用・転用の操作は定義しない。内部構造とライブラリは規定しない。コンパイルの最終成果物はCP932バイト列であり、`roman=kana` レコード列の出力はその中間生成物である。CP932で表せない値の検出は、バイト列の生成時に行う。

用語: マッピングは、ローマ字キーとかな値の対応付け。規則的な行は、五十音の行のように一定の生成規則で複数のマッピングを対応付ける宣言単位。個別マッピングは、単一のローマ字キーとかな値の対応付け。宣言は、規則的な行と個別マッピングの組合せで完全なマッピング集合を構成するTypeScript定義であり、宣言が構成したマッピング集合だけがコンパイルの入力になる。

## 振る舞い

| Given | When | Then |
|---|---|---|
| 規則的な行と個別マッピングで完全なマッピング集合を構成する有効なTypeScript宣言 | コンパイルする | 宣言が対応付けたすべてのマッピングと、行キーが空文字でない規則的な行ごとの `行キー\=行キー` の対応を出力に含める。出力はこれらのみを含める。コンパイル結果は宣言の内容だけで決まり、OS設定を変更しない。 |
| 同じマッピング集合になる、宣言順だけが異なる2つのTypeScript宣言 | それぞれコンパイルする | 生成バイト列は完全に一致する。 |
| 同じローマ字キーを異なるかな値へ複数回対応付ける宣言（個別マッピングと規則的な行の衝突を除く） | コンパイルする | 重複を示して失敗し、完成した出力を生成せず、OS設定を変更しない。 |
| 個別マッピングが規則的な行の生成と同じローマ字キーで衝突する宣言 | コンパイルする | 個別マッピングのかな値を優先して含め、失敗しない。 |
| 同じローマ字キーに同じかな値を複数回対応付ける宣言 | コンパイルする | 該当マッピングを1件として含め、失敗しない。 |
| ローマ字キーまたはかな値に `=`、CR、LF、NUL を含む宣言 | コンパイルする | 禁止文字を示して失敗し、完成した出力を生成せず、OS設定を変更しない。 |
| CP932で表せないローマ字キーまたはかな値を含む宣言 | コンパイルする | 表せない値を示して失敗し、完成した出力を生成せず、OS設定を変更しない。 |
| マッピングが320件以下の宣言 | コンパイルする | 生成に成功する。 |
| マッピングが321件以上の宣言 | コンパイルする | 件数上限を示して失敗し、完成した出力を生成せず、OS設定を変更しない。 |
| 正常にコンパイルできる宣言 | コンパイラを引数なしで実行する | コンパイルと登録を1ステップで行い、生成バイト列を `HKCU\SOFTWARE\Microsoft\IME\15.0\IMEJP\RomaDef\CustomRoma` のBinary値 `table` として登録する。 |
| 正常にコンパイルできる宣言 | `--preview` を付けてコンパイラを実行する | OS設定を変更せず、規則的な行ごとのマッピング、個別マッピング、マッピング件数と320件の上限を表示する。 |
| 正常にコンパイルできる宣言、かつ現在適用中の `table` がある環境 | `--diff` を付けてコンパイラを実行する | 現在適用中の `table` の内容とコンパイル結果の差分（追加されるマッピングと除去されるマッピング）を表示する。差分がないときは、差分がない旨を表示する。OS設定を変更しない。 |
| 正常にコンパイルできる宣言、かつ現在適用中の `table` がない環境 | `--diff` を付けてコンパイラを実行する | 現在適用中の `table` がない旨と、すべてのマッピングが追加対象であることを表示する。OS設定を変更しない。 |
| 存在しない行キーへの参照を含む宣言 | コンパイルする | 該当する参照を無視してコンパイルする。OS設定を変更しない。 |
