# MS-IME キー設定スナップショットの適用と差分

対象は、`undotfiles/ime/msime-stylelist-custom.reg` に保存した MS-IME のキー設定スナップショットを `just msime` タスクから適用し、差分を表示する機能である。利用者は、このリポジトリで Windows 環境の MS-IME 設定を管理するオーナーである。

スナップショットは、`HKCU\Software\Microsoft\IME\15.0\IMEJP\StyleList\Custom` とそのサブキーを `reg.exe export` で保存した UTF-16LE の .reg ファイルである。スナップショットの更新（GUI での設定変更と `reg.exe export`）はこの spec の対象外の手順で行う。

ローマ字表のコンパイルと適用の振る舞いは `custom-roma-def.spec.md` に従う。この spec は、ローマ字表とキー設定を 1 つのタスクへ統合する振る舞いと、キー設定スナップショットの適用・差分表示を定める。

用語:

- レコード: キー設定のバイナリ値の中の、NUL 区切りの `キー名=割り当て` 形式の 1 項目。キー名は最初の `=` の左側全体とし、空白も含める。
- 値の状態: 値ごとの比較結果であり、一致・変更・スナップショットのみ・レジストリのみの 4 種とする。値の状態は、値の種類を含む内容の一致で判定する。
- temp ディレクトリ: OS 標準の一時ディレクトリ（Windows では `TEMP` 環境変数の指す先）。

## 振る舞い

| Given | When | Then |
|---|---|---|
| 有効なスナップショットがある環境 | `just msime` を実行する | ローマ字表の適用（`custom-roma-def.ts` を引数なしで実行）、キー設定の適用（`msime-key-settings.ts` を引数なしで実行）の順に行う。前段が失敗したときは後段を実行しない。 |
| レジストリに `StyleList\Custom` がある環境 | キー設定を適用する | 適用の前に現在の `StyleList\Custom` を temp ディレクトリへ `reg.exe export` でバックアップし、バックアップ先のパスを表示する。 |
| レジストリに `StyleList\Custom` がない環境 | キー設定を適用する | バックアップを作らず、その旨を表示して適用を続行する。 |
| `StyleList\Custom` の在否判定または export が失敗する環境 | キー設定の適用または差分を実行する | 現在の設定がない環境と同じ振る舞いをする。適用ではバックアップを省略して続行する旨を表示し、差分では現在の設定がない旨を表示する。 |
| `StyleList\Custom` があるがバックアップの export が失敗する環境 | キー設定を適用する | バックアップの失敗を示して失敗し、スナップショットを適用しない。 |
| スナップショットの import または `keystyle` の設定が失敗する環境 | キー設定を適用する | 失敗した旨を示して終了する。それまでに完了した変更は保持する。ロールバックはしない。 |
| reg.exe を実行できない環境 | キー設定を適用する | その旨を示して失敗し、レジストリを変更しない。 |
| 有効なスナップショットがある環境 | キー設定を適用する | スナップショットを `reg.exe import` し、`StyleList\Custom` 配下の値がスナップショットの内容になる。 |
| 有効なスナップショットがある環境 | キー設定を適用する | `HKCU\Software\Microsoft\IME\15.0\IMEJP\MSIME` の `keystyle` が `Custom` になる。 |
| 有効なスナップショットがある環境 | `just msime diff` を実行する | OS の設定を変更せず、ローマ字表の差分（`custom-roma-def.ts` に `--dry-run` を付けて実行）とキー設定の差分（`msime-key-settings.ts` に `--diff` を付けて実行）を順に表示する。前段が失敗したときは後段を実行しない。 |
| レジストリに `StyleList\Custom` がある環境 | キー設定の差分を表示する | 配下の値ごとに値の状態を表示する。バイナリ値に変更があるときは、レコード単位の追加・削除・変更（同じキー名で割り当てが異なるレコード）を表示する。 |
| レジストリに `StyleList\Custom` がない環境 | キー設定の差分を表示する | 現在の設定がない旨と、スナップショットの全レコードが追加対象であることを表示する。 |
| スナップショットの内容がレジストリと一致している | キー設定の差分を表示する | 差分がない旨を表示する。 |
| スナップショットファイルがない、または解析できない形式の値を含む | キー設定の適用または差分を実行する | その旨を示して失敗し、レジストリを変更しない。 |
| `apply` または `diff` 以外のモード引数を指定する | `just msime <mode>` を実行する | 指定したモード値を示して失敗し、レジストリを変更しない。 |

## 未確定事項

- スナップショットが GUI 変更より古いことの検出はしない。GUI 変更後の再 export は手動で行う。
