# MS-IME 設定管理

対象は、宣言の集約結果をMS-IME用のバイナリ値へコンパイルして適用する機能と、保存したMS-IMEキー設定スナップショットを適用・比較する機能である。宣言の記法と集約の規則は `../SPEC.md` の「ローマ字表の宣言」に従い、このspecでは記述しない。利用者は、このリポジトリでWindows環境のMS-IME設定を管理するオーナーである。

`just msime` は、ローマ字表の適用（`msime/roma-def.ts` を引数なしで実行）、キー設定の適用（`msime/key-settings.ts` を引数なしで実行）の順に行う。前段が失敗したときは後段を実行しない。`just msime diff` は、ローマ字表の差分（`msime/roma-def.ts` に `--dry-run` を付けて実行）、キー設定の差分（`msime/key-settings.ts` に `--diff` を付けて実行）の順に表示する。前段が失敗したときは後段を実行しない。

キー設定スナップショットは、`HKCU\Software\Microsoft\IME\15.0\IMEJP\StyleList\Custom` とそのサブキーを `reg.exe export` で保存したUTF-16LEの `undotfiles/ime/msime/key-settings.reg` である。スナップショットの更新（GUIでの設定変更と `reg.exe export`）はこの仕様の対象外の手順で行う。

## 用語

- レコード: キー設定のバイナリ値の中の、NUL区切りの `キー名=割り当て` 形式の1項目。キー名は最初の `=` の左側全体とし、空白も含める。
- 値の状態: 値ごとの比較結果。一致・変更・スナップショットのみ・レジストリのみの4種とする。値の状態は、値の種類を含む内容の一致で判定する。

## ローマ字表のコンパイルと適用

コンパイルは、宣言の集約結果を `roman=kana` レコード列へ変換し、CP932バイト列へエンコードする。`roman=kana` レコード列の出力は中間生成物である。CP932で表せない値の検出は、バイト列の生成時に行う。

### 振る舞い

| Given | When | Then |
|---|---|---|
| 宣言の集約結果 | コンパイルする | 行キーが空文字でない規則的な行ごとの `行キー\=行キー` の対応をレコードに含める。出力は集約結果とこれらのみを含める。コンパイル結果は宣言の内容だけで決まり、OS設定を変更しない。 |
| `行キー\` をローマ字キーとするマッピングを既に含む宣言 | コンパイルする | そのマッピングを優先して含め、失敗しない。 |
| 同じマッピング集合になる、宣言順だけが異なる2つのTypeScript宣言 | それぞれコンパイルする | 生成バイト列は完全に一致する。 |
| ローマ字キーまたはかな値に `=`、CR、LF、NUL を含む宣言 | コンパイルする | 禁止文字を示して失敗し、完成した出力を生成せず、OS設定を変更しない。 |
| CP932で表せないローマ字キーまたはかな値を含む宣言 | コンパイルする | 表せない値を示して失敗し、完成した出力を生成せず、OS設定を変更しない。 |
| マッピングが320件以下の宣言 | コンパイルする | 生成に成功する。 |
| マッピングが321件以上の宣言 | コンパイルする | 件数上限を示して失敗し、完成した出力を生成せず、OS設定を変更しない。 |
| 正常にコンパイルできる宣言、かつ現在適用中の `table` がある環境 | コンパイラを引数なしで実行する | 現在適用中の `table` の内容とコンパイル結果の差分（追加されるマッピングと除去されるマッピング）を表示してから、生成バイト列を `HKCU\SOFTWARE\Microsoft\IME\15.0\IMEJP\RomaDef\CustomRoma` のBinary値 `table` として登録する。登録に成功したら、登録したマッピング件数を表示する。差分がないときも差分がない旨を表示して登録する。 |
| 正常にコンパイルできる宣言、かつ現在適用中の `table` がない環境 | コンパイラを引数なしで実行する | 現在適用中の `table` がない旨と、すべてのマッピングが追加対象であることを表示してから、生成バイト列をBinary値 `table` として登録する。登録に成功したら、登録したマッピング件数を表示する。 |
| 正常にコンパイルできる宣言、かつ現在適用中の `table` がある環境 | `--dry-run` を付けてコンパイラを実行する | 引数なしの実行と同じ差分（追加されるマッピング、除去されるマッピング、または差分がない旨）を表示し、OS設定を変更しない。 |
| 正常にコンパイルできる宣言、かつ現在適用中の `table` がない環境 | `--dry-run` を付けてコンパイラを実行する | 引数なしの実行と同じく、現在適用中の `table` がない旨と、すべてのマッピングが追加対象であることを表示し、OS設定を変更しない。 |
| 現在適用中の `table` の取得が失敗する環境 | コンパイラまたはコンパイラの差分を実行する | 現在適用中の `table` がない環境と同じ振る舞いをする。 |
| 正常にコンパイルできる宣言 | `--preview` を付けてコンパイラを実行する | OS設定を変更せず、規則的な行ごとのマッピング、個別マッピング、マッピング件数と320件の上限を表示する。 |
| 任意の宣言 | `--diff` を付けてコンパイラを実行する | 未知の引数としてエラー終了し、OS設定を変更しない。 |

## MS-IMEキー設定スナップショットの適用と差分

### 振る舞い

| Given | When | Then |
|---|---|---|
| 有効なスナップショットがある環境 | キー設定を適用する | スナップショットを `reg.exe import` し、`StyleList\Custom` 配下の値がスナップショットの内容になる。 |
| 有効なスナップショットがある環境 | キー設定を適用する | `HKCU\Software\Microsoft\IME\15.0\IMEJP\MSIME` の `keystyle` が `Custom` になる。 |
| レジストリに `StyleList\Custom` がある環境 | キー設定を適用する | 適用の前に現在の `StyleList\Custom` をtempディレクトリへ `reg.exe export` でバックアップし、バックアップ先のパスを表示する。 |
| レジストリに `StyleList\Custom` がない環境 | キー設定を適用する | バックアップを作らず、その旨を表示して適用を続行する。 |
| `StyleList\Custom` の在否判定またはexportが失敗する環境 | キー設定の適用または差分を実行する | 現在の設定がない環境と同じ振る舞いをする。適用ではバックアップを省略して続行する旨を表示し、差分では現在の設定がない旨を表示する。 |
| `StyleList\Custom` があるがバックアップのexportが失敗する環境 | キー設定を適用する | バックアップの失敗を示して失敗し、スナップショットを適用しない。 |
| スナップショットのimportまたは `keystyle` の設定が失敗する環境 | キー設定を適用する | 失敗した旨を示して終了する。それまでに完了した変更は保持する。ロールバックはしない。 |
| `reg.exe` を実行できない環境 | キー設定を適用する | その旨を示して失敗し、レジストリを変更しない。 |
| 有効なスナップショットがある環境 | `just msime diff` を実行する | OSの設定を変更せず、ローマ字表の差分とキー設定の差分を順に表示する。前段が失敗したときは後段を実行しない。 |
| レジストリに `StyleList\Custom` がある環境 | キー設定の差分を表示する | 配下の値ごとに値の状態を表示する。バイナリ値に変更があるときは、レコード単位の追加・削除・変更（同じキー名で割り当てが異なるレコード）を表示する。 |
| レジストリに `StyleList\Custom` がない環境 | キー設定の差分を表示する | 現在の設定がない旨と、スナップショットの全レコードが追加対象であることを表示する。 |
| スナップショットの内容がレジストリと一致している | キー設定の差分を表示する | 差分がない旨を表示する。 |
| スナップショットファイルがない、または解析できない形式の値を含む | キー設定の適用または差分を実行する | その旨を示して失敗し、レジストリを変更しない。 |
| `apply` または `diff` 以外のモード引数を指定する | `just msime <mode>` を実行する | 指定したモード値を示して失敗し、レジストリを変更しない。 |

## 未確定事項

- 320件上限が対象MS-IME環境で現在も有効であること。
- スナップショットがGUI変更より古いことの検出はしない。GUI変更後の再exportは手動で行う。
