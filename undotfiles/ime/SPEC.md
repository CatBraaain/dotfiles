# ローマ字表の宣言

対象は、MS-IMEとMozcの両方の日本語入力で共有するローマ字表の宣言データ（`roma-table.yaml`）である。宣言データはMS-IME用コンパイラ（`msime/SPEC.md`）とMozc用コンパイラ（`mozc/SPEC.md`）がそれぞれ読み込み、集約 engine（`roma-table.ts`）でマッピング集合を構成してから、各自の形式へ反映する。利用者は、このリポジトリでWindows環境のIME設定を管理するユーザーである。

## 用語

- マッピング: ローマ字キーとかな値の対応付け。
- 規則的な行: 五十音の行のように一定の生成規則で複数のマッピングを対応付ける宣言単位。
- 個別マッピング: 単一のローマ字キーとかな値の対応付け。
- 宣言: 規則的な行と個別マッピングの組合せで完全なマッピング集合を構成するデータ定義（`roma-table.yaml`）。宣言が構成したマッピング集合だけがコンパイルの入力になる。
- tempディレクトリ: OS標準の一時ディレクトリ。Windowsでは `TEMP` 環境変数の指す先を使う。

## ローマ字表の宣言

宣言の集約は、空の状態から宣言の完全なマッピング集合を構成する。既存の表やOS設定を集約の入力にはしない。内部構造とライブラリは規定しない。集約したマッピング集合が、MS-IMEとMozcの各コンパイラの入力になる。

### 振る舞い

| Given | When | Then |
|---|---|---|
| 規則的な行と個別マッピングで完全なマッピング集合を構成する有効なTypeScript宣言 | 集約する | 宣言が対応付けたすべてのマッピングを含める。マッピング集合は宣言の内容だけで決まり、OS設定を変更しない。 |
| 同じマッピング集合になる、宣言順だけが異なる2つのTypeScript宣言 | それぞれ集約する | 生成されるマッピング集合は完全に一致する。 |
| 同じローマ字キーを異なるかな値へ複数回対応付ける宣言（個別マッピングと規則的な行の衝突を除く） | 集約する | 重複を示して失敗し、完成したマッピング集合を生成しない。 |
| 個別マッピングが規則的な行の生成と同じローマ字キーで衝突する宣言 | 集約する | 個別マッピングのかな値を優先して含め、失敗しない。 |
| 同じローマ字キーに同じかな値を複数回対応付ける宣言 | 集約する | 該当マッピングを1件として含め、失敗しない。 |
| 存在しない行キーへの参照を含む宣言 | 集約する | 該当する参照を無視して集約する。OS設定を変更しない。 |
